# Administrative names for factory-region hints

`pca-code.json` is the 2023 province/city/county name dictionary from
[Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China/blob/master/dist/pca-code.json).
The upstream project is distributed under [WTFPL v2](https://github.com/modood/Administrative-divisions-of-China/blob/master/LICENSE).

SHA-256: `83b7536f853ad16beb4d37b92890a3fd7bb9d33d4f37e7c8885fb948749a9bc4`.

Only public administrative names are included. No factory or procurement records
are embedded. Province/city/county names help interpret the current factory text;
they do not verify a company's actual dispatch address. Unrecognized, conflicting,
or ambiguous locations remain unknown. This dictionary is a fixed historical
reference, not a live administrative-boundary service.

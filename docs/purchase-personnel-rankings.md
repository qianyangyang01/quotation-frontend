# 采购人员排名

采购资料维护新增默认收起的排名入口。点击展开后才请求统计；收起时取消未完成请求，收起期间不随页面刷新读取排名。统计说明集中在独立的默认收起区域。

## 统计口径

- 全部采购：统计当前权限允许的普通采购及 FOB 资料，不提供来源下拉。接口权限沿用采购目录权限。
- 在售 SKU：复用已配置销量文件的主 SKU 清单，精确匹配，不推断子 SKU。未匹配单列，不算个人缺失。
- 补全率：按当前采购报价人归属，已完整 SKU / 总 SKU。同一 SKU 跨来源仅计一次，各份资料均完整才算完整；归属不一致或未填写人员单列，不分配给某个采购人。
- 普通采购完整条件：正式 SKU、正重量/起订量、有效采购价、明确票点、已知 1 件运费或明确包邮。旧资料价格须大于 0。FOB 检查重量原文、已解析的起订量、价格、运费。此口径与可报价资格独立，不改变报价资格。
- 异常：只读取正式完成的采购价格异常事件，覆盖普通/组合、FOB 单条与逐项、批量单品审核。忽略领取、取消、修正和未处理行的重复快照。
- 时间：近 7/30/90 天为到请求时刻的滚动窗口，全部时间自历史开始。按审核事件时间，不按报价创建时间。缺时间的异常报价单列，不推断日期。
- 去重：同一报价 ID + SKU 在所选时间内计一项；采用区间内首次采购异常事件保存的采购归属，后续资料归属修改不覆盖历史归属。多 SKU 同一报价可以多项。
- 关联报价数：所选时间内完成过审核、关联该采购人的去重报价数；异常报价采用事件归属，非异常采用当前资料归属。异常占比使用异常报价数 / 关联报价数，不是异常项数 / 关联报价数，不代表责任认定。
- 历史未分类报价、未归属异常单列，不推断采购责任。导出包含筛选和口径，并保护文本单元格免于公式执行。

## 安全与验证

`GET /api/v1/purchase-rankings` 使用只读一致性事务，只投影必要资料字段和审核事件。无数据库迁移，不回写采购资料、历史报价、审核状态或金额。

单元测试覆盖去重、多人/多 SKU、历史人员归属、分类、未知日期、销量范围、零值及来源合并。PostgreSQL 集成测试执行真实 SQL、普通/FOB/批量审核投影、权限和读取前后指纹比较。组件测试覆盖默认收起不加载、展开加载、收起取消和过期响应隔离。发布和线上验收证据按版本保存在本地 release-packages。

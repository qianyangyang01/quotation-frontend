# 物流问题定位与日期说明修复

## 需求与影响范围

问题审核页以前只显示数量，部分错误将原始行号写在消息里却保留 `row=0`，跨工作表合并也可能丢失 Sheet 来源，导致无法定位或误标同号行。本次改动贯穿来源解析、只读错误定位补充和价格审核页；不修改运费计算方式、正式价格、数据库结构或发布门槛。

新增日期说明处理：`生效时间`、`生效日期`及明确完整日期不参与渠道/重量/价格识别。Excel 日期类型和合并单元格同样处理；原始单元格仍保留在解析证据中。只忽略元数据单元格，不整行删除；同一行的真实重量范围（如0–2.0KG）、运费和国家仍参与识别。无法确定为纯日期的业务说明不被一概丢弃。

回归中确认两处误判路径：Excel日期底层数字被遗漏价格扫描当作金额；日期过滤后的空单元格被拼接成分隔符，导致固定重量表仍尝试解析日期行。两处均已修正，日期正则复用预编译对象。解析版本更新为`providers-2026.09.07-v12`，便于区分新旧导入证据。

## 实现

- 新解析错误保存 Sheet、行号列表及原始内容；跨表重叠保留两侧来源。
- 已有草稿读出时兼容旧版“原始行号：[x,y]”文字格式。只能唯一确定来源时补充 Sheet，多 Sheet 同号歧义不冒充精确定位。
- 完整价格、编辑模式和问题页直接展示错误原因与原表位置；已解析问题行标红并显示原因。
- 定位按钮跳转到包含目标行的页并滚动定位；切换视图不重置用户修改。
- 尚未解析为价格的原表行单独列出，明确无法在价格表内标红，避免用户修改无关行。
- 渠道级错误明确说明没有具体行位置，保留现有阻断。

## 回归用例

- 单一Sheet定位、多Sheet同号歧义、rowKey优先、跨表冲突两侧定位。
- 老错误行号列表兼容、未解析原表行、无具体位置的全表问题。
- 原值显示转义，不能执行原表内容；点击定位不修改价格。
- 无关阻断不会错误附着到其他错误的价格行。
- 日期文字及Excel日期类型放在表头前、表头旁、有效价格行旁、空白区域和表尾；合并单元格；仍保留正确固定重量、公斤价、每票费和原表证据。
- `0-2.0 KG`、`0.101-0.3`、`1.001-20`不因日期过滤被误删。
- 草稿在线修正、正式价格隔离与既有物流解析回归。

# 仅复制报价单：成本与重量摘要

在创建时间之后、国家报价表之前增加两行六项数据，HTML 富文本与纯文本复制共用相同内容。沿用现有列宽、配色、报价数量筛选与窄表换行规则。

- 计算含税单价：本记录计入采购价，组合商品按每套 SKU 件数汇总；不再次应用当前票点。
- 计算运费：首选渠道唯一的 1 件/套物流样本金额，零运费有效。不使用数量不明的 `freightCny`。
- 最终合计成本：1 件/套采购成本、国内运费和上述国际运费相加。国内运费复用现有保存快照处理；不使用对应自定义数量的渠道总成本，也不将标准化后的默认零值当作已保存成本。
- 产品、包材、合计重量：优先读取 1 件/套重量快照。包材包含标准包材及整票特殊包装；旧记录可使用明确对应 1 件/套的物流输入。仅保存总重的记录保留总重，不反推分项。
- 缺失、数量不匹配或歧义项显示“未保存”。底部注明首选国家、分区、物流商、渠道及数量。

未修改价格计算、报价记录或其他复制功能。只扩展此按钮原先的字段范围，不复制佣金、内部备注、账号及操作费。

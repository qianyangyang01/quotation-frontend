## 识别与计费

- 完整渠道名称与产品 ID 双重校验，不能用“包含敏感”匹配。仅规范空格、换行及全角括号。
- 按表头定位列，支持换列、标题行下移、工作表改名以及合并国家/渠道/产品单元格。
- 两个渠道均由表尾明确的 0.1kg 起重补重；首档包含起重，后续相邻档左开右闭。
- 全渠道共享从原始精度列构造的分段进位：2kg 以内 1g，超过 2kg 为 100g。先补重、进位，再匹配价格档，防止 2kg 附近不同档位重复命中。
- 沿用现有“公斤价＋每票费”引擎。软包装免泡、盒装体积重/8000、尺寸限制、超尺寸附加费、税费及收寄要求保留为原表说明和复核提示，不宣称已支持自动计泡或附加费，也不修改税费政策。
- 按用户 2026-10-28 补充确认，两个渠道的可寄属性均为“带电、化妆品、保健品”；目录与无目录解析结果均使用这三个明确属性。原始品类说明完整保留，未增加全局属性等价关系。
- 缺价格/挂号费/重量/精度、公式缓存、名称与代码冲突、国家错误、档位缺失/重叠、起重或限重缺失均阻断相应渠道。不得把缺失价格当零。

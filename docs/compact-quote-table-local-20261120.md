## 使用方式

普通报价单、报价记录列表及记录详情新增“复制图文表格”。不需要先预览或打开详情，直接点击后在 WPS 使用普通粘贴。列表按钮点击时才读取完整已保存记录并临时加载图片，复制结束即释放组件；读取或等待剪贴板时若记录版本、账号变化则取消，避免复制错行或过期内容。

- 导出 SKU、Product、Size Rules、Country / Zone、当前数量列的价格、Logistics Provider。
- 已纠正早期本地预览使用固定列顺序的问题：列组跟随当前报价单 columnOrder，数量表头和价格同步使用当前数量顺序，行保持当前行序。移动列组、数量列或报价行后直接复制，不需要先重新预览。
- 通过 HTML 和纯文本剪贴板提供可编辑单元格，价格使用数值格式 0.00，不是整张图片。
- 连续相同 SKU 只写一次，以纵向合并单元格显示；商品图片和尺码区域同步合并。保留当前行序，不能跨越其他 SKU 强行合并。
- 商品图片嵌入 HTML 为 PNG 数据，不依赖临时网址或再次上传。WPS 实测作为图片对象锚定到合并图片区域。
- 复制后可展开“查看图文表格”检查内容。复制失败不会静默退化为丢图的纯文本成功提示。
- 合并物流按保存的成员和权重显示，例如“50%顺丰商派 + 50%燕文”；等权三条显示约 33.33%，避免将显示精度误称为精确权重。

## 价格与历史隔离

导出读取当前报价单或历史记录的现有价格，不调用新报价、不查询当前物流计算价格，也不修改保存的平均方案。隐藏行不导出，但仍保留为合并方案的来源；合并结果使用保存的客户价格。现有完整报价图片按钮保留，FOB 独立报价单不加入本次按数量物流表格按钮。

前端在等待图片及剪贴板锁时检查记录、报价和版本状态；数据变化后不继续写入过期表格。复制操作没有保存接口调用，不影响审核、处理、成交状态。

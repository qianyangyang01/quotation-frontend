# 报价单紧凑布局与默认模板入口

范围：本地前端修改，基于 `e696a5a`，分支 `codex/quote-sheet-compact`。未部署生产。

- 删除客户报价单、显示列、图片、列排序、价格算式、隐藏行和平均报价区域的大段常驻说明；保留实际错误、缺失数据和状态提示。
- 将显示列、图片管理、平均报价入口、预览、复制和新增列集中到表格上方。桌面操作栏随报价表滚动吸顶，窄屏正常换行。
- 删除“临时商品图”标题，添加/管理图片按钮使用紫色 `#7c3aed`，最小高度 44px，最小宽度 142px。
- 缩小表头、行高、输入框和列宽；物流商下方保留渠道和区域，完整来源信息保留在悬停提示中。
- 新页面和清空重新开始默认进入“我的报价模板”；再次发起及撤回编辑仍恢复原报价方式。
- 报价计算、历史价格、审核、处理、成交状态及后端数据未修改。

验证：

- 全量前端测试：182 个文件通过、9 个文件跳过；1358 项通过、11 项跳过。
- `pnpm build`、`pnpm lint`、`git diff --check` 通过。
- 本地真实组件、示例数据浏览器验证：生成平均行、预览后返回编辑、打开/取消图片弹窗、30 行长表格操作栏吸顶、768px 窄屏。
- 示例普通行高约 59px，表头总高约 81px。图片按钮实际高 44px、背景 rgb(124,58,237)。
- `outputs/quote-sheet-compact/desktop.png` 和 `narrow.png` 为本地验证截图，未作为生产验收。

生产部署前需重新核对当时生产版本，合入本次修改并执行正式发布验证。

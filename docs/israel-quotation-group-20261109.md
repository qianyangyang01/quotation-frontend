# 以色列报价入口合并

报价工作台的物流属性将“以色列自提”“以色列到门”合并显示为“以色列”。选择后直接加载以色列，合并两类有效财务授权渠道；渠道仍以稳定渠道键区分，各自计价。快速报价、模板渠道选择及报价汇总在渠道名称旁显示紫色“自提”、蓝色“到门”标签。两类均授权的渠道显示两个标签。

财务维护继续保存原来两个独立属性，不迁移财务配置。重复或停用策略不授予对应渠道权限，合并入口不授权其他国家。旧草稿或再次发起载入工作台时转换为统一入口；没有批量更新历史报价、价格、审核或成交状态。

前端和后端需要一起发布：后端增加合并属性的运价查询及提交授权校验；共享国家别名补充 IL / 以色列 / Israel。没有数据库迁移。

本次仅完成本地实现，未部署生产。

验证覆盖：126 项前端测试、14 项后端测试通过；包括真实工作台挂载后恢复旧属性、请求以色列运价、生成自提和到门两行及三个数量档，停用/重复授权、跨国隔离、各渠道重量边界价格不变、旧草稿往返，以及原有报价价格安全回归。类型检查和生产构建通过。

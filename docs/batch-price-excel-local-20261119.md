# 批次价格明细下载（本地）

本地分支：`codex/batch-price-excel-local-20261119`，基线 `12890fc8`。未推送、未发布，未修改数据库和历史报价。

## 使用

在价格更新概览右上角点击“下载批次明细”，读取完所选批次后点击“下载 Excel”。

- 当前批次全部国家、属性、分区和重量段，不受列表筛选和分页影响。
- 汇总、涨价、降价、不变、其他变动五张表。每张表都有原生 Excel 表格筛选，水平和垂直居中，冻结表头及识别列。
- 明细包含原／新单价、固定费、差额、单价涨跌幅，以及原／新版本、原始批次、源文件和计费规则。按票区间价单独放列，不冒充每公斤价。
- 以发布版本及明确基线为准。同一渠道多次发布逐次保留，不使用当前版本代替历史版本。缺失明确基线时列为无可比价。
- 对齐前后计费重量区间，保留开闭边界。按克进位且整数克边界显示为 `1–500` 等形式，其他情况用区间括号明确边界。
- 分类比较价表费用项，不是任意重量的最终总运费承诺。费用反向变化、计费／适用规则变化、重叠档位、币种变化单列，避免按单一 1 kg 结果归类。
- 非人民币保留原币种，不进行汇率换算。新增、移除和缺价不补零。

## 本地预览

```powershell
node scripts/dev-batch-price-export.mjs
```

打开 `http://127.0.0.1:5226/dev/batch-price-export/index.html`。

此入口使用单独样例数据，可实际下载。它没有配置生产 API 代理，样例不会注入正式数据源。系统组件已接入现有只读版本接口 `/logistics/rebuild/versions/{id}`，按需读取原始重量段，最多三个并发请求。关闭窗口或切换账号会取消读取。

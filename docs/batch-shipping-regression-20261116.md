## 本轮发现并修复

1. 原始批量报价单快照可能覆盖后来保存的署名、联系方式、尺码说明。恢复时改为优先采用记录最新可编辑快照，主动清空也正确保留。
2. 保存客户报价会更新记录版本；原重置逻辑会把标题和版式暂时恢复为默认。改为按保存的报价单快照恢复，增加连续保存的回归断言。
3. 保存完成后的只读报价表缺少克重分隔线。补齐同一分组边界，翻页后仍正确。
4. 从记录生成整批图片时遗漏共同商品图片。恢复共享图片；若各条图片已分别修改，则明确提示分别复制，避免错误地把某条图片作为整批共同图片。
5. 修正原图片重置测试与新增批量重置键的绑定断言，保留原普通报价照片保留/账号切换清理行为测试；补齐本地演示脚本的 ESLint 环境声明。

后台新用例初次出现一项测试设定错误：既有“取消报价”流程移除活动记录，新用例误把它当作回收站记录读取。按现有流程改为断言剩余成员快照不变和正确数量，未改变业务代码。修正后 28 项全部通过。

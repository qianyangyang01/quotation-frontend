# 粘贴时自动判断包邮

用户要求采购粘贴的包邮标记随 1 件、10 件、100 件总运费自动对应。

- 任一档明确大于 0，包邮自动为“否”，即使原标记是“是”。例如 6/11/56、3/0/0。
- 三档都明确为 0，包邮自动为“是”，即使原标记是“否”。0、0.00 等等价数字均支持。
- 空白不等于零；没有正运费、三档又未全部明确为零时不推断，沿用粘贴字段及现有空白保留规则。非法数字仍阻止保存。
- 两个采购粘贴入口共用规则，粘贴后立即回显；在粘贴表格内继续修改运费会同步标记。预览、确认保存的字段由同一判断得到。
- 仅更正当前粘贴行的包邮字段，不改运费数字、阶梯、票据或列序。不批量修改采购资料，不重算历史报价，不改变 Excel 导入、石墨自动同步或独立编辑表单的规则。

实现范围仅前端采购粘贴模块，沿用既有服务端预览、版本检查、事务保存和审计。

验证：7 个相关测试文件、107 项通过，覆盖两个入口的回显与保存请求、正数/混合零/全零/空白/非法数字/局部粘贴/后续编辑；TypeScript 检查通过。

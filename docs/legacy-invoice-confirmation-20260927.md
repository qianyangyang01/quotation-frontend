# 老采购票点确认与石墨核对

报价查询现在检查 `legacy_2026` 商品的票类型。如果仍为“待确认”，弹窗说明“采购票点为待确认，不可报价”，要求采购在系统确认票点、票类型后重新查询。单品、组合和新报价保存接口执行同一规则。明确票类型的 0% 票点仍可报价。非老数据沿用原规则。

前端每次查询读取采购 API，并在当前采购资料变化后同步阻止物流计算、加入报价单和保存。后端从锁定的采购行读取票类型，不相信客户端票点或采购版本是否存在。历史已保存报价和审核状态不批量更新。

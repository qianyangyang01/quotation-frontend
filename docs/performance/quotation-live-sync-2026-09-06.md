# 采购新增与报价同步：实施和验证报告

## 结论与业务边界

采购正常新增商品后，业务员在已经打开的报价页输入 SKU 并查询，即读取服务器最新商品，无需刷新页面。无关商品新增不触发整库重载、当前报价重算或保存阻断。

页面可见期间约每 5 秒核验当前报价引用的 SKU 版本和轻量物流版本；后台标签暂停，重新聚焦、联网后立即核验。5 秒为请求完成后的间隔，不承诺零延迟推送。主动查询始终读取最新数据，不等待轮询。

物流库版本变化仅作为检查信号：按已选国家、区域、渠道和显示数量档核对运费、可用性及运输时效。无关变化后台更新可查询规则，保留当前表单；相关变化提示“更新报价”。用户更新后保留客户、数量及渠道选择并重新计算。正式报价历史快照不回写，恢复草稿使用当前数据。

## 影响范围、风险与处理

| 模块 | 调整 | 主要风险与防护 |
| --- | --- | --- |
| 采购查询 | 单品、组合、草稿恢复按 SKU 请求最新资料 | 快速换 SKU 取消/丢弃过期结果；查询失败阻止误存残留商品 |
| 报价同步 | 当前 SKU 版本戳包含版本号和更新时间 | 不扫描采购整库；删除重建同名 SKU 不复用旧版本 |
| 物流查询 | 背景读取不清空已展示规则 | 无关物流更新不导致空列表/持续不可保存；返回代次再次核对 |
| 保存 | 引用商品及选定物流在事务中核验 | 只锁引用商品和渠道；旧客户端保持原兼容路径 |
| 财务 | 非编辑时检查物流版本并刷新目录 | 编辑中推迟，防止覆盖未保存表单 |
| 页面生命周期 | 可见检查、请求不重叠、失败退避、退出取消 | 网络异常明确显示并允许恢复，不把失败解释成无配置 |

主要文件：`QuotationSystemView.vue`、`JerryModuleView.vue`、`quotationSync.ts`、`purchaseStore.ts`、`publishedLogisticsRepository.ts`、`QuotationSyncController.java`、`PurchaseProductService.java`、`QuotationReadinessService.java`、`LogisticsQuotationGuard.java`。新增两个鉴权同步路由，沿用现有报价 JSON 保存载荷；无数据库迁移、生产 Compose 资源调整或培训系统变更。

## 功能与异常用例

| 用例 | 验证方式及结果 |
| --- | --- |
| 页面先打开、采购后新增、业务不刷新查询 | 本地登录浏览器成功读取 SYNC-UI-0906，成本 10 元 |
| 当前商品成本更新 | 浏览器显示采购资料变化；手动更新采用新成本 |
| 保留编辑内容及已选渠道 | 浏览器保留“实时同步本地验收”、同一 SKU 与性能普货专线，重新计算后成功保存；数据库确认 1 条该客户正式记录 |
| 无关商品新增 | 独立采购账号新增，当前 SKU 版本不变，业务保存成功；50 用户持续新增结果同样通过 |
| 改价后直接提交旧报价 | 接口返回 409；没有写入旧报价 |
| 非法及超量 SKU 核验 | 非法字符及 101 个请求项返回 422 |
| 权限边界 | 采购、物流访问报价核验返回 403；业务修改采购返回 403 |
| 不存在 SKU | 浏览器查询失败且不能保存；另加输入 SKU 与已加载商品不一致的保存保护 |
| 无关国家运费变化 | PostgreSQL 测试：德国变化不拒绝美国报价 |
| 当前运费、数量档、渠道停用变化 | PostgreSQL 测试拒绝旧数据和错误运费；旧客户端仍保留整库版本校验 |
| 后台规则刷新 | 前端测试确认预加载期间不替换当前展示规则 |
| 慢请求、隐藏标签、断网恢复、退出 | 定时器测试无重叠，隐藏暂停、恢复继续、退出停止 |

## 发布与回滚

目标版本 `quotation-2026.09.06-01`；回滚版本 `quotation-2026.09.05-17`。GitHub 推送并核对准确 SHA 后，由干净提交构建带版本和 SHA 标签的本地镜像，校验上传压缩包；发布脚本先备份 PostgreSQL、MinIO 与镜像清单，通过健康检查后切换 current。无迁移，回滚应用版本时保留发布后新增的业务数据，不恢复旧数据库覆盖新记录。

生产仅做低频只读技术和登录页面检查；不执行此目录的写入负载脚本。GitHub、生产部署、技术健康、登录浏览器验收分别记录在发布包中。

## 验收限制

这些数据是短时隔离接口对照，不能代替生产 50 人页面交互 p95，也不是 50 人同时上传 Excel。之前 30 分钟角色混合负载和导入测试见 [上一轮报告](quotation-roles50-results-2026-09-06.md)，其结果不冒充本次新代码的长时间浸泡测试。广泛关键词搜索、冷启动、真实公网抖动及生产终端体验需持续观察；没有以此次 SKU 精确查询结果宣称所有查询均小于 100 ms。

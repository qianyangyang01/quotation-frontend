# FOB 报价保存及报价单交互

FOB 使用现有报价记录、归属权限、审核、抽检及生命周期，但采用独立的服务端计算和 JSON 快照，不通过国际物流渠道的校验或 0.05 美元取整流程。

- 报价单填写客户名称后保存；支持全部阶梯、当前数量，两种范围均保留报关及不报关价格。
- 保存采购来源原文、读取时间、采购阶梯、国内运费、10% 票点、系数、汇率、小额订单规则及最终价格。
- 报价单保存标题、署名、日期、联系方式、说明、行顺序、列顺序及两种价格列顺序；支持鼠标拖拽和方向键排序。
- 服务端锁定当前采购资料，核对读取时间及汇率并独立验算价格。过期或篡改输入返回错误，不产生部分记录。
- 同一提交重试复用幂等键；已成功保存后重复点击不会生成第二张记录。输入变化时使用新的提交键。
- 我的记录、管理员记录显示 FOB 类型，可按报价类型筛选。详情和复制只读取保存快照；CSV 导出包含 FOB 两种价格，仅在结果包含 FOB 时追加列，普通导出格式不变。
- 抽检标记、取消标记、审核及账号隔离复用现有服务。FOB 不提供“同渠道免审”。
- 再次发起读取当前采购资料并生成新报价，原记录不变。FOB 不进入普通渠道的撤回草稿及客户价格编辑器，相关服务端入口也拒绝不兼容操作。

没有数据库迁移，没有历史数据重算或更新脚本。上线前应通过 frontend 全量回归及 backend CI；新测试涵盖源数据校验、超时重试、并发幂等、真实账号归属/管理员/财务读取、抽检往返、历史不可变、拖拽映射、筛选及导出。线上仅只读验收，保存测试使用隔离 PostgreSQL。

回滚说明：旧版本不能完整展示新 FOB 快照。出现问题优先前向修复；若上线后已经产生 FOB 报价，切回旧应用前必须评估兼容性，禁止删除或转换新记录以适配旧代码。

## 行为

- 美国、澳大利亚：勾选至少两条有效渠道后自动生成平均行，编辑渠道、普通/加权模式、权重、展示方式、名称或时效会更新同一方案。其他国家保持原手动生成行为。加权合计必须等于 100%，沿用 Decimal 计算和原四舍五入规则。
- 未完成/无效平均设置阻断复制及保存前快照捕获；关闭设置面板或切换国家不能绕过阻断。回到已有方案会明确恢复该方案最后有效的设置，可继续编辑。清空所选渠道移除本次自动平均；新增方案允许另建独立方案。
- 批量 SKU 和批量克重使用各自系统价格生成方案，先全批验证再应用；缺价、缺渠道不会留下部分已生成结果。后续增加或减少成员会更新原方案 ID，避免堆积旧平均行。
- 美国平均行固定在当前连续 SKU 块最上方，拖拽、方向键和上下移均不能将它下移。其他行仍保留手工顺序；不跨其他 SKU 重组分散的同 SKU 行。预览、图片、图文/数据复制、保存采用同一顺序。
- 新报价保存行顺序快照，重开保持一致。已保存历史报价仍按原快照显示，仅打开不会重算或重排；只有用户主动编辑才处理设置。
- 修改方案名称、时效、展示方式时保留已手改客户平均价格及未完成的价格输入错误，不偷偷还原价格。新报价源价格、渠道或数量变化时仍按原保护机制要求重新确认平均方案；不以自动生成绕过价格校验。
- 仅“复制图文表格”输出增加“报价人 / 报价日期 / 报价客户 / 客户等级 / 客户佣金”五个橙色列头，放在 Product/SKU 等表头左侧同一行，下方对应单元格留空。报价单、报价记录列表和详情共用。五列固定在复制内容左侧，其余部分继续跟随当前行列顺序；不向业务快照添加元数据或推断佣金。不改变报价图片、普通数据复制或屏幕表格的列头。

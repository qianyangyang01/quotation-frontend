# 化妆品、保健品物流属性接入

基于生产提交 cde28cce155074aa7a586b13270a5227990965d5 开发。

## 行为和顺序

财务物流属性策略与报价条件共用列表：普货、化妆品、保健品、带电、纯电池、液体、粉末、非液体化妆品、带磁、微敏感。报价计算说明也从此列表生成。

化妆品、保健品是独立策略键，不转换成普货或非液体化妆品；旧的非液体化妆品选项保留。新增选项不会自动创建策略或授权渠道，需财务按国家明确选择现有渠道。

## 影响链路与处理

| 模块 | 核对与处理 |
| --- | --- |
| 财务策略 | financeChannelPolicies.ts 提供统一选项；新属性不加入兜底默认授权。JerryModuleView 直接使用该列表。保存和载入按独立 category 保留。 |
| 报价条件与计算 | QuotationSystemView 读取同一列表，未授权属性明确无可用渠道；不按产品品类自动推断物流属性。 |
| 价格查询 | LogisticsQueryService 移除化妆品转非液体化妆品的隐式别名。价格规则查询缓存本来已包含 attribute，两个新属性不会共用缓存键。 |
| 前端规则匹配 | logistics.ts 同步移除旧别名，使显式允许/禁止标记准确匹配。已计费验收渠道沿用现有重量计价机制和财务授权机制。 |
| 后端财务保存 | FinanceSettingValidation 已支持非空且唯一的字符串属性；并发 If-Match、财务权限与审计沿用，新增验证测试，不新增白名单破坏旧自定义策略。 |
| 后端报价提交 | LogisticsQuotationGuard 已严格匹配属性、国家与渠道，测试覆盖普货授权不能用于新属性、错误国家/渠道拒绝、停用策略拒绝。 |
| 采购数据 | 产品品类中已包含化妆品、保健品，与物流属性不是同一字段。无需改商品资料、Excel列或自动映射商品品类。 |
| 模板与草稿 | 模板保留渠道稳定标识；报价草稿独立保存物流属性。测试覆盖两个新属性、旧属性与澳大利亚双分区共同回读。 |
| 历史与导出 | 历史物流属性按原始字符串保存和展示，未迁移历史快照，不重新计算历史金额。 |
| 公司88渠道与导入 | 渠道原有物流属性属于源渠道元数据，参与识别项身份；此次不修改解析器的渠道命名推断、不改变公司渠道ID及财务绑定，不重新导入或发布价格。 |

## 风险与上线边界

- 已经以“化妆品”保存的自定义策略将按其本名查询，不再借用非液体化妆品标记。存在明确标记限制的渠道可能不再返回，需按原表核对。
- 财务新增策略是实际业务授权，不应在代码发布时自动复制普货或旧非液体化妆品渠道配置。
- 新增属性不证明某物流商接受所有形态的化妆品或保健品；原表的液体、粉末等说明及收寄条件仍需财务/物流核实。
- 不涉及数据库迁移、旧价清理、税费公式改变、用户权限修改或培训系统。

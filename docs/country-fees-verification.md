# 国家税费与附加费

发布基线：cd38f2c（生产 quotation-2026.09.07-05），分支：codex/quotation-country-fees-release。已整合原税费提交 9afbe8e。

## 行为

- 财务“税率设置”改为“税费与附加费”：左侧选择国家，右侧分别设置国家关税和附加费（USD/单）、启用状态、渠道豁免。
- 每项费用分别按整单收取一次。附加费实际进入首选报价、1/2/3/自定义数量、单品/组合报价、人民币换算和复制至 Excel 的最终金额。
- 旧国家关税和物流商免税默认规则保持兼容；新增附加费默认关闭。渠道可覆盖物流商默认关税，免关税不代表免附加费。
- 国家关税明确设置后允许零值或关闭；保留线上无关税规则：国家未配置、关闭或金额为零均不收关税；附加费仍独立计算。
- 新报价记录保存实际附加费、国家金额、启用和豁免状态；历史记录读取不重算，明细以保存时的数据展示。
- 保存失败保留编辑内容；非法金额禁止保存；取消修改恢复最近保存值。渠道支持搜索、物流商筛选、10/30/50 条分页，默认 10。

## 与物流任务的契约

已与“评估物流接口接入难度”（01a07a5b-06ae-74b1-8e00-d0b6f388624c）同步，并得到确认。

继续使用 tax-settings，新增可选字段：

- countries[]：taxConfigured、surchargeFeeUsd、surchargeEnabled。
- channelFees[]：country、channelKey、taxMode、surchargeMode；模式为 exempt/taxable，缺省继承。
- quoteOptions[]：surchargeUsd、countrySurchargeUsd、surchargeExempt、surchargeEnabled。

channelKey 复用 financeChannelKey(rule.id, relation)，即规则 ID + 物流商 + 渠道代码（缺省渠道名）。不修改物流目录和解析实现。旧 key 保留并提示不可用，不按同名渠道自动套用豁免。首选渠道无法唯一识别或失效时阻止保存。

物流重建引入 companyChannelId 后，物流侧使用经验证的旧 key → 新 key 映射迁移 channelFees，保留国家维度、显式收取/豁免、原映射审计；冲突阻断。历史报价费用快照不重算。

共享文件仅有财务入口、报价传参/快照等局部改动：JerryModuleView.vue、QuotationSystemView.vue。后续合并双方提交后统一验证发布，不能用任一独立分支覆盖另一项功能。

## 账号分页与上线基线兼容

账号列表默认每页 10 条，可选 30/50 条，支持首页/上一页/下一页/末页。搜索、角色筛选和每页条数变化回第一页，结果缩小时收敛到有效页。23 条本地模拟数据实测末页 3 条、搜索回首页、切换每页 30 条显示 23 条；没有创建或修改生产账号。

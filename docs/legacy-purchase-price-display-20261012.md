# 老数据未税单价优先展示

采购列表、单品报价及组合报价优先展示明确的未税单价，辅助显示票点和实际计入采购成本的含票价。只有含票价的老数据明确标记“含票价”和“未税单价待确认”，不倒推未税价格。单价格采购列表显示起订量；多阶梯保留区间和逐档价格。

实现由独立的 legacyPurchaseDisplay 生成只读展示信息。报价产品的 purchase / purchaseUnitPrice 和 purchaseBaseUnitPrice 保持既有语义，保存请求和草稿请求不增加展示字段。实际计价继续调用 quotationCalculator，无计价规则、后端、数据库或历史报价变更。

## 价格验算

- 未税 110、票点 10%：主展示 110，计价仍为 121，不变为 133.10。
- 后续未税阶梯 121、票点 10%：计价 133.10；不得误认为该档已含票。
- 5 套，每套 2 件基准价 121 + 3 件第二档 133.10：总采购成本 3206.50。
- 未税 100、票点 8%：含票 108。
- 未税 19.99、票点 13%：含票 22.59。
- 自动模式 0.05、票点 1%，含票四舍五入仍为 0.05：不得因金额相等而重复加点。
- 老数据明确保存未税 110、含票 125 时，展示 110 和原含票 125，不因展示重新生成 121。
- 0 票点保留既有独立 1% 报价调整并明确标注；不将其标为采购票点 1%。

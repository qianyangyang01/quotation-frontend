# 客户报价单价格算式

价格单元格支持 `+ - * /` 和括号，也接受 `× ÷`、全角括号和可选的 `=` 前缀。按回车或离开输入框后显示金额；最终结果使用现有十进制工具四舍五入到两位小数。例如 `42.6/0.95` 得到 `44.84`，`6/0.95` 得到 `6.32`。这是客户手动改价，不重复应用佣金或系统报价的 0.05 向上取整。

只输入金额时保留原有两位小数规则；空值仍表示不报价。算式长度、嵌套和数字长度受限，不执行 JavaScript 或 Excel 公式，不支持引用单元格。除零、非法表达式、负结果和超额结果显示错误，并阻止预览、复制和捕获保存价格。

所有输出共用报价单金额模型，失焦之前直接复制或保存也使用计算结果。持久化继续保存数字快照，不新增数据库字段、权限或全局配置。原系统价格保持独立；数量调整、渠道排序、切换商品和历史快照恢复沿用现有隔离行为。

验证覆盖：运算优先级、十进制舍入、输入限制、单品/组合、回车/失焦重复确认、复制与图片模型与保存金额一致、非法算式三处阻断、渠道排序、数量复用、旧快照和商品切换。全量前端 918 通过、2 跳过，类型检查、构建及 lint 通过。

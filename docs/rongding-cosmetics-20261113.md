# 容鼎化妆品商派渠道，2026-11-13

用户标注的 PK00270(A) 已对应公司渠道“美国纯商派化妆品专线”。生产六档价格与提供的 2026-11-12 原表一致，保留原渠道、正式版本及财务配置，不重复创建。

新增 PK00369(A)“美国标准DDP专线-特惠化妆品A(SP)”。仍通过已发布的容鼎完整产品代码解析器识别，导入范围仅此新增公司渠道；不登记同单元格 PK00379(C)，也不更新其他容鼎渠道。原文件及价格来源由正式导入服务留存。

两者各六档、50g起计、最高5kg、8–12天，人民币公斤价加一次每票处理费。原表尺寸、体积重和派送范围说明保留复核提示。沿用现有容鼎化妆品分类；新 DDP 渠道配置美国化妆品授权及包税。未给出的价格或重量范围不补零、不猜测。

美国化妆品专线A(SP)为商派；特惠渠道为特惠商派。共享展示组件识别这两个准确名称及全角括号，显示“商派”，分别提示相应邮编表及到货预报限制，禁止显示“全邮编”。原标准名称已含“商派”，继续不显示全邮编。

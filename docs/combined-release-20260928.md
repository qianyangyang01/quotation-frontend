# 2026-09-28 合并发布

本次以线上 `quotation-2026.09.28-03`（`1d9e3330314583295b5b5fdf918ef0d7197705b2`）为基线，合并最近已确认、尚未上线的两项修改。

- 客户报价单移除冗长常驻说明，压缩间距、表头和行高，操作栏集中并吸顶；保留醒目的紫色图片按钮。新页面及清空后默认进入“我的报价模板”，再次发起仍恢复原报价方式。
- 平均报价来源行可以隐藏、恢复。全部来源隐藏后仍保留 AVG 行、计算依据和客户价格；预览、复制、记录回显保持一致。后端只移除“来源行不得隐藏”的限制，继续校验来源存在、可用性、金额、权重及税费口径。
- 合并冲突位于平均报价面板：保留紧凑布局的面板锚点，同时传入完整来源行，避免隐藏后丢失方案计算依据。

保留已在线的保存超时、重试去重、渠道加载恢复等修复。数据库迁移、物流计费、财务税费配置和历史报价金额不在本次代码变更范围。南非云速递 3 条渠道的 1 USD/单关税已经通过后台单独发布。

发布前执行前端全量测试、lint、构建、Compose 校验和后端 `mvn clean verify`，并比对新旧后端 JAR 的全部历史迁移及物流规则资源。发布证据、备份校验和回滚脚本保存在报价项目统一的 release-packages 版本目录。

桌面主目录和旧工作区的历史残留修改不直接覆盖生产，也不删除；本发布分支仅合入上述当前待发布改动。

# 女装单品与组合报价

## 使用

报价工作台的「报价模式」新增「女装单品 SKU 报价」「女装组合 SKU 报价」。查询商品、采购阶梯、物流属性、国家渠道、个人报价模板、客户操作费、佣金阈值和客户报价单均沿用现有流程。女装模式显示「按金额自动匹配」，不再选择 S–E 客户等级，不叠乘等级系数。

选档金额为每条国家／渠道、每个报价数量的（计入采购成本＋国内运费＋该数量国际运费）÷ 当次美元汇率。组合以对应套数的全部商品合计计算。选档使用未取整金额，不能用已经乘系数的售价再次选档。

| 金额（USD） | 默认系数 |
| --- | --- |
| 0 ≤ 金额 < 20 | 1.27 |
| 20 ≤ 金额 < 30 | 1.25 |
| 30 ≤ 金额 < 50 | 1.23 |
| 金额 ≥ 50 | 1.22 |

基础售价＝综合成本×命中系数；后续人民币精度、换汇、税费、附加费、客户操作费、佣金阈值、美元0.05向上取整均复用现有计算。边界20／30／50归后一档；整笔金额乘系数，跨档可能导致售价下降，不做隐含平滑。

## 财务维护

「财务 → 女装报价系数」支持启停、编辑上限及系数、增加／删除档位、金额试算、预览变更、发布。区间从0起连续，末档无上限；1至12档，金额上限不超过1,000,000，系数大于0且不超过10，最多6位小数。只允许具有财务权限的账号发布。

配置使用 finance_setting 的 womens-pricing 项及原有乐观锁版本。界面版本为数据库 version＋1。发布记录包含修改前后策略和版本；已打开的女装报价须刷新后保存。未发布、停用、无效配置时停止女装新报价；普通报价不依赖此项。

## 模块联动

| 模块 | 行为 |
| --- | --- |
| 单品／组合工作台 | 复用SKU、采购阶梯、票点、国内运费、普通／特殊包材、物流计费与渠道权限 |
| 快速报价、个人模板 | 相同选择流程；每个数量独立选档 |
| 客户报价单 | 复用价格编辑、数量新增、图片预览、复制与保存；组合单位为套；不显示内部系数 |
| 保存校验 | 服务器锁定当前女装配置和汇率；核对版本、政策、数量、商品成本、物流成本、区间、系数和基础售价；沿用原报价金额／物流／税费校验 |
| 我的／公司报价记录 | 新类型筛选、类型标记、自动系数说明、规则版本与按数量计算依据 |
| 审核、异常项、成交 | 沿用原流程；女装组合的SKU识别按组合处理 |
| 撤回编辑 | 保留原流程和修订记录；重新提交时校验当前规则；前后对比展示版本 |
| 再次发起 | 带入女装模式和原输入，按当前资料生成新报价，不复制旧规则作为当前政策 |
| 导出／对账 | 筛选导出带版本与说明；具备完整计价权限的内部对账展示系数、成本及基础售价 |
| 采购排行 | 女装组合按组合内SKU统计 |
| 原单品、组合、批量单品、FOB、试算、代发 | 保留原模式；本次未新增女装批量报价 |

## 历史与权限

保存记录携带 womensPricing 策略版本快照，quoteOptions 各自携带 womensPricingSamples。1、2、3、自定义数量及报价单新增数量均保存。查看、复制、导出历史记录读取快照，不使用当前配置补算。缺少快照时明确提示不能推算。普通业务员可看计价方式和版本；系数遵循财务可见权限；成本明细要求采购、物流、财务完整权限。

V65迁移仅在缺少配置时插入默认系数，不更新报价、审核、草稿、成交或物流记录；已存在政策不覆盖。财务发布亦不批量重算历史。再次发起生成新报价；用户主动撤回重提仍遵循原有重新审核机制。

## 验证与发布边界

单元测试覆盖金额边界、无效配置、禁用、模式识别、历史快照、重新发起、报价单单位、导出及展示权限。PostgreSQL测试覆盖真实jsonb、首次初始化、重复迁移不覆盖、发布与保存的事务锁及过期版本拒绝。浏览器保存样本作为服务端契约测试，包含女装单品、组合和第4价格数量列。

本地浏览器验收脚本与截图位于 artifacts/womens-quotation-20261103，采用合成商品／运价与隔离API响应；不表示已写入生产。发布需按 deploy/README.md，采用干净提交、前后端一起发布、执行V65迁移、完整备份和旧静态资源保留，并复核生产健康及历史数据不变。回滚至不识别女装模式的旧版前，应检查是否已有女装报价；保留数据和策略，避免旧界面误展示。

# 库存说明选填与组合 SKU 查询布局

- 是否有货为可留空的文字说明，粘贴、采购编辑及导入保留自定义内容；常用值继续可选，粘贴中的有/无继续兼容为有货/无货。
- 删除界面及模板表头的必填星号，旧 Excel 的是否有货*表头保持兼容。库存说明不参与报价资格、成本或运费计算。
- 采购粘贴更新继续空白保留原值、预览确认、版本校验及修改审计；在编辑页可主动清空。没有数据库迁移、历史报价重算或状态重置。
- 组合模式的报价条件在宽屏显示为五列；查询全部 SKU 移到组合商品明细右侧，与添加 SKU 同组。每行查询保留，并扩大输入框和按钮，调整六列表格比例；窄屏表格独立横向滚动。
- 原逐行与批量查询方法保持不变，逐行查询成功后无需再批量查询。单品查询入口保持原位。

验证：前端全量 1571 通过、14 条条件跳过；布局联动专项 28 通过。库存后端专项 47 通过且无跳过，包含独立 PostgreSQL 保存回读、预览、空白保留和审计。ESLint、类型检查、生产构建、Compose 隔离检查通过。桌面 1880px 与窄屏 390px 使用实际组件预览验证。

发布范围为前后端；正式发布、CI、备份及线上验收证据另存版本目录。验收只读，不创建线上测试报价或采购记录。

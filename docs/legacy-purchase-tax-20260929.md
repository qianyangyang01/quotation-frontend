# 旧采购资料票点与报价快照修复

## 复现依据

报价 QT20260929025458E0FDDC 的 AZ2601758 保存采购价为 6.80、计价票点为 0。
生产只读核查确认，该报价引用采购版本 2（2026-09-27T14:25:06.046315Z）；该版本票点已从 0 更新为 0.01，原始报价、旧含票价均为 6.80。
此前计算器对所有非零票点的 legacy_2026 商品直接采用旧最终价，并将 invoiceRatePercent 固定为 0。

## 修复范围

- 明确 0 票点继续按原价乘 1.01；有旧原始报价时使用原始报价，避免对含票最终价再次乘算。
- 旧数据明确采用原始报价，或旧最终价与保存的原始报价相同，按已确认的当前票点计入采购成本。AZ2601758 为 6.80 × 1.01 = 6.87。
- 有独立含票价格且与原始报价不同，或缺少原始报价时，保留已有最终价格，不从含票价再叠加税点。
- 旧数据保留实际采购票点用于快照，不再一律写成 0；单品、组合编辑器说明实际价格来源。
- 未调整采购资料、国内运费、历史报价、审核或成交状态。历史单的读取仍只展示保存值；新查询和主动重新报价使用修复逻辑。

该组合新计入采购成本为 7.45 × 2 + 6.87 = 21.77 元/套，国内运费仍为 2.60 元/套。
仅修正此采购差异且沿用原单运费时，1 套成本为 52.50 元，3 套成本为 111.51 元；这是对比验算，未写回历史单。

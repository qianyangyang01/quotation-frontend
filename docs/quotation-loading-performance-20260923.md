# 报价加载与图片预览性能排查

基线: production quotation-2026.09.23-20 / dedb3b8a37deb9aaf74f34b9041b32477b3923c6，后端 -19。修复分支 codex/quotation-loading-performance-20260923；用户已确认提交部署，实际发布证据保存在对应版本发布包。

## 已确认原因

1. 每次查询/切换物流属性，runQuoteLogistics强制刷新已读财务设置；hydrateFinanceSettings(force:true)将hydrated设为false；quotationAttributeOptions变空，条件控件将暂时空集合解释成未授权。修复后复用本页已核验设置；发现syncPending变更时仍强制刷新。页面初始化、后台版本轮询及保存前强制核验保持不变。
2. applyDraftPayload用普通对象p放入products后，异步物流加载继续修改原始p，没有经过Vue代理。实际数据已完成，商品子组件仍显示加载中。改为一开始创建reactive产品。新增真实挂载测试在原实现下稳定失败：数据状态已变为“当前条件没有已发布物流渠道”，DOM仍为“正在加载”。修复后通过。
3. normalizeRule在依赖未就绪时可能显示授权/无渠道结论。增加财务/物流加载与错误状态区分；常用国家矩阵收到来源状态后，不再将加载中或错误显示为无财务授权。
4. 图片预览点击后才加载3张固定PNG素材（197470+153107+479524=830101字节），而后才进行Canvas及PNG编码。现在组件挂载后以低网络优先级预载，共用同一Promise，失败后点击可重试。图片设计、像素资产、计算、输出尺寸和临时图片不上传的边界不变。

## 实测及范围

- 线上已登录浏览器，原草稿7条渠道，素材缓存后点击到预览约297ms（包含自动化往返），浏览器error为空。
- 本机公网单文件GET：brand总5.488秒/首字节5.060秒，notes总2.522秒/首字节1.909秒，header总3.649秒/首字节3.180秒。顺序单次采样，不能相加当作浏览器并行下载总耗时。
- 本地真实浏览器基准：通过Vite同源代理读取同一生产公开素材，3张并行首次预载2402ms。模拟报价、实际renderer/Canvas/toBlob，不连接业务API，不复制业务数据。
- 素材就绪后，3次真实PNG生成：2行60/26/24ms；7行39/34/29ms；24行67/72/56ms；50行（3页）116/100/149ms。
- 说明：预加载将素材等待提前，不代表降低公网延迟；用户立即点击或网络中断仍可能等待/提示重试。以上不是生产并发P95，也不是后端接口延迟测量。
- 单次线上资源快照：后端CPU0.86%、PostgreSQL4.88%、解析0.05%；只能说明该采样时刻无饱和，不能排除间歇性网络或导入资源竞争。

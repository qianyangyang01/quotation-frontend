# 中包渠道及以色列属性配置

本次使用用户重新提供的 `物流渠道属性表(1).xlsx.crdownload`，ZIP 完整可读。WPS 的工作表维度误写为 A1:A1，读取实际单元格后为 113 行、13 列。

## 范围

- 云途中包特惠带电、普货已在生产发布，本次保留现有渠道 ID 和运价版本。
- 新增万邦中包挂号含电、普货的增强解析及渠道登记，源报价为 20260831-45213VIP 文件。
- 按表配置列出的 112 行渠道。其中用户明确暂不处理第57–58行的两个燕文专线快递渠道。
- 用户确认第22–23行勾反：云途大货特惠带电对应大货带电，特惠普货对应大货普货。
- 以色列自提和以色列到门为两个独立财务授权属性，仅配置以色列。未覆盖以色列运价的勾选保留为未配置说明，不臆造价格。

## 联动

- 财务和报价使用统一属性选项，补齐香水、大货普货、大货带电及两个以色列属性。
- 默认策略固定为原有属性集合，新增选项不自动继承美国或普货授权。
- 后端查询、报价提交、策略保存按属性、国家和稳定渠道键校验，测试覆盖新增属性独立性。
- 草稿按原始字符串往返保存。历史报价、模板、审核和成交状态不迁移、不重算。
- 属性表只更新列出渠道在列出属性中的授权；未列出的顺友等渠道、其他财务设置和已有价格限制保持原状。
- 国家匹配通过正式国家简码归一化（例如 AE 阿联酋、LV 拉脱维亚）。公司渠道通过精确名称、登记别名匹配；万邦大货普货、急速渠道使用已核对的明确名称映射，不模糊猜测。
- 既有停用或计费待核验渠道仅维护授权，不强制启用价格。

## 执行与验证

`scripts/logistics/prepare-attribute-matrix.py` 只读取文件与生产快照，生成待应用策略、逐渠道源行和差异报告。生产应用另用带版本、原始 payload、物流版本指纹前置条件的事务，保存备份、审计和回读结果。

前端 `attributeMatrix.corpus.test.ts` 对实际待应用配置逐属性、逐国家验证，并核对未列出授权不变；后端通过财务验证器验证相同 payload。万邦源表及边界运费另有前后端对照案例。

最终部署版本、配置版本、备份及验收结果保存于本次发布证据目录并在交付时报告；本文件不将本地测试等同于生产完成。

# 系统上线问题诊断报告

## 1. 当前架构

| 层级 | 实现 | 数据流 |
|---|---|---|
| 前端 | Vue 3、Vite、TypeScript、Vue Router | 页面经同源`/api/v1`访问报价后端；浏览器仅保留UI偏好 |
| 后端 | Java 21、Spring Boot 4.1、Security、JPA、Flyway | Controller校验、Service事务、Repository访问PostgreSQL |
| 认证 | 报价独立账号、Redis Session、CSRF、五角色RBAC | 后端校验Session和权限，不接受培训Cookie |
| 数据 | PostgreSQL 16 | 业务表、幂等、审计、迁移批次、JSON快照 |
| 文件 | 独立MinIO | 商品图、实物图、导入文件、迁移分卷；数据库仅存对象元数据 |
| 部署 | Docker Compose | `quotation-prod`生产栈；`quotation-uat`独立验收栈 |
| 入口 | 共享Nginx按域名转发 | `vip.ahmln.com`仅进入报价前后端；8088不暴露公网 |

## 3. 影响模块

- 前端：采购工作台、物流规则、财务设置、报价创建/记录、客户/供应商、公开分享、迁移导出、顶部导航和路由。
- 后端：序列化、Hibernate JSON、采购导入、商品、物流、财务、客户、供应商、报价、迁移、对象存储、幂等、审计、鉴权。
- 数据库：新增Flyway V6-V8；客户、供应商、供应商商品、物流投影、报价作废/分享、迁移批次、对象暂存生命周期和对象外键清理索引。
- 部署：Docker镜像字体、Compose参数化、UAT覆盖、前端Nginx、CI隔离与跳过测试检查。
- 生产入口：仅报价域名维护门禁；培训业务容器与数据不在改造范围。

## 4. 异常处理策略

- 重复点击/网络重试：前端禁用，后端`Idempotency-Key`和唯一约束。
- 刷新/关闭/服务重启：导入和迁移任务、检查点持久化。
- 空值/非法格式/超长文本：Bean Validation及业务字段校验，返回422和字段信息。
- 过期会话/越权：401/403，并写报价独立审计。
- 数据不存在/版本冲突：404/409，不做静默覆盖。
- Excel错误：预览区分阻断错误和警告，阻断错误不允许确认。
- 文件攻击：真实类型、大小、ZIP路径、条目数、压缩比例、解压总量和SHA-256校验。
- 数据库/MinIO失败：事务回滚，临时对象不转正式，定期清理无引用暂存对象。
- 分享安全：仅存令牌哈希，默认7天，可撤销；公开响应不含成本、利润和审计字段。

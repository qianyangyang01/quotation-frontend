# 报价记录选择完整 / 隐藏行后的报价单

基线：`2f016165c734c354ca9879193e21f968dcf69291`（本地发布证据对应 quotation-2026.09.24-14）。独立工作区：`record-quote-sheet-visibility-20260924`。

## 行为

- 新报价保存客户报价快照时，将隐藏行映射为稳定的报价渠道 ID，全部渠道、客户价格和系统价格仍完整保存。
- 后台记录存在隐藏行时，点击“复制报价图片”按钮，直接选择“完整报价单 / 隐藏行后的报价单”后打开对应预览；取消按钮上方独立的版本选择框。图片预览弹窗内仍可切换，图片、报价单表格和对账数据按所选版本输出。
- 查看完整版本不会清除隐藏设置。记录内保存客户报价及单独改价时均保留隐藏设置；显式恢复全部后保存空数组。
- 服务端校验隐藏渠道必须属于原记录，不接受重复、未知或非法 ID。旧客户端只改价而未携带隐藏字段时，保留已保存的隐藏设置。
- 全部行隐藏时阻止空版本复制，可切换完整版本。历史记录没有隐藏设置时沿用完整报价，不推断过去的临时隐藏操作。
- 不重算报价、不修改历史金额、不触发审核/确认重置，不需要数据库迁移。需同时发布前后端，旧后端会丢弃新增字段。

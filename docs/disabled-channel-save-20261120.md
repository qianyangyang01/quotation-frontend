# 停用渠道不阻断其他渠道保存

原首选渠道失效时，恢复报价会清空首选，但保存校验仍要求首选。前一版自动补齐首选明确排除了这个场景，导致当前清单中其他正常渠道也无法保存。

本次保留已选停用/未授权渠道的标识及原因，价格为空；不再从恢复清单删除。失效首选可从当前已核验的可用清单补齐，保存汇总使用清单中的有效渠道，不再额外要求旧首选存在。模板已知渠道标识失效后不会按同名渠道套价。仍执行真实报价、财务、税费和数据版本校验；全部渠道均无有效报价时不能生成虚假的金额。

仅修改前端，不更改运价、后端、数据库或历史记录；用户主动重新提交仍按原业务流程处理。

验证：完整前端 319 个测试文件通过、2776 项通过，19 个文件/24 项原有可选测试跳过。真实 Chrome 隔离 API 验证快速报价/模板、再次发起/撤回编辑四种组合：停用原首选保留空价及原因，其他渠道提交成功，唯一有效首选与汇总一致，原报价快照保持不变。测试中的价格及客户为模拟数据，不写入生产业务。

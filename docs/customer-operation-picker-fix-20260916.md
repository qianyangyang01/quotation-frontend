# 客户操作费在报价页无法选择

## 原因与修复

- 截图中的草稿姓名“测试客户1”与财务客户 BK、CK、DK 不匹配。原下拉组件把已恢复的客户姓名直接作为搜索条件，点击展开也会过滤掉全部财务客户。本次保留并验证工作区已有的修复：浏览列表与主动输入搜索分开，展开时显示全部启用客户，实际输入时才过滤。
- 报价工作区异步加载财务配置后，只回填国家、税费、附加费和渠道，漏了客户操作费。正常应用入口会预加载财务配置，但入口读取失败后由工作区重试、或缓存为空时，组件初始化得到的空客户列表无法更新。本次在工作区配置返回值及页面初始化中补齐客户操作费。
- 保持明确选择客户才收费的规则；手动输入同名客户不绑定费用，停用客户不显示，零费用客户仍可选择。

## 验证

- 新增完整 `QuotationSystemView` 挂载回归，模拟财务接口延迟返回，覆盖空姓名、恢复“测试客户1”、恢复已选 CK。修复前 3 项均能复现空列表或错误的失效提示，修复后通过。
- 前端全量：716 项通过、2 项跳过；类型检查、Vite 构建、相关文件 ESLint 通过。
- 本地浏览器使用真实报价页面和内存模拟接口，验证恢复旧姓名后展开 BK $0.30、CK $0.40、DK $1.00，并选择 BK 显示“公司操作费 $0.30/单”。费用计算回归同时覆盖单品、组合及各数量列。
- 本次没有提交、推送或部署；没有修改生产财务配置或业务数据。浏览器验收为本地模拟接口，不代表生产登录验收。

# 客户报价单图片

## 使用与数据边界

在“报价单预览与保存”中的“客户报价单”区域编辑署名、日期和各行运输时效，点击“预览报价单”，再“复制报价图片”到聊天窗口。

“复制报价数据”复制同一展示模型的英文表头和全部渠道（Tab 分列、换行分行），可粘贴到 Excel / WPS。美元保留两位小数及 `$`，缺失显示 `—`；不包含内部渠道说明、成本、人民币、成交结果或底部条款。数据复制不要求先生成图片，使用当前时效编辑；图片分页时仍一次复制全部行。

“我的报价记录”和“报价记录”详情右下角都有图片、数据复制按钮。图片按钮打开相同报价单预览后再复制；数据按钮直接复制。两者共用当前详情内的临时编辑，关闭图片弹窗后释放 PNG，时效文字编辑保留至关闭详情或记录上下文更新。署名使用记录业务员，日期默认当天。仅使用保存的 quoteOptions / 历史指定报价快照，不查询当前运价、不用成交价替换报价、不补算缺失档位；旧记录没有自定义数量时表头显示 Custom。

- 国家使用简称，英国在客户报价单中显示 UK；原始国家及 GB 代码不变。
- 运输时效来自对应渠道；支持补填、调整及恢复。缺失显示 `—`。
- 处理时间固定 `1-2 days`，四档美元价格只读；组合报价使用 set/sets。
- 同一国家、物流商的多条渠道仍分别列出。编辑表保留来源描述用于区分渠道和区域，客户图片不包含这些内部信息。
- 只允许编辑署名、日期和运输时效。修改不回写正式报价、物流数据或报价草稿。
- 每张最多 24 条渠道；超过时分图，序号连续，每张重复表头，完整条款只出现在最后一张。切换后逐张复制。
- 复制失败会保留预览并明确提示，可用浏览器右键“复制图片”；不自动下载。

**生成的客户图片只存在于浏览器内存中。** 不上传、不写数据库、不写 localStorage/sessionStorage/IndexedDB、不建立图片历史、不自动下载。
修改、源数据更新、切换上下文、组件退出时撤销旧 Blob URL；取消中的生成结果不能重新成为可复制预览。
`src/assets/quote-sheet` 是固定版式素材，构建时发布一次，体积固定，不随每日客户报价数量增长。

## 版式与接入

确认图是 `codex-clipboard-7957711a-ba27-4a8a-b9f7-d931f4c30548.png`。六行基准图为 1536×1024。
品牌区、固定表头和四条英文说明使用原图无损区域；动态 Shipping Time 和数量表头替换原示例内容。
绝不导出示例姓名、日期、金额或 SAMPLE DATA 页脚。

`customerQuoteSheet.ts` 负责独立展示模型及转换；`customerQuoteSheetRenderer.ts` 负责 Canvas 和内存 PNG；`CustomerQuoteSheet.vue` 负责编辑、预览、复制和取消过期渲染。
`QuotationPreviewSave.vue` 接入客户预览，保留内部基本信息和正式保存校验。
`quotationRecordQuoteSheet.ts` 将历史快照转为相同展示模型；`QuotationRecordCopyActions.vue` 接入两个记录页面共用的详情组件。`customerQuoteSheetClipboard.ts` 复制表格文本，剪贴板拒绝时显示失败，不误报成功。
云速递的英文品牌按其官网 https://www.sfydexpress.com/ 映射为 SFYD Express，与云途 YunExpress 区分。
其他三个矩阵原有 Excel 文本复制不变；沿用当前生产版本的 quotationRowsSignature 完整行签名，已有三种模式的时效变更回归测试覆盖。

不新增 API、数据库字段或图片存储服务。无法识别国家简称或物流商英文映射时给出具体提示，不猜测其他物流商名称。

## 本地验证（2026-09-12）

- 类型检查、相关 ESLint、Vite 构建通过。
- 全套 Vitest：239 项通过，1 项既有测试跳过（增加记录快照与表格复制验证后）。
- 记录复制：以本机 Edge 挂载真实两个 scope 的记录页面，拦截 GET 接口提供虚构历史快照；验证重复国家/物流商渠道、缺失值、编辑后图片与数据共用时效、拒绝权限提示、PNG 剪贴板及无业务写请求、无浏览器存储。未连接生产账户。
- Excel：浏览器按钮复制的 TSV 已读取验证，并将同一内容送至 Windows 剪贴板，在新建的隐藏 Excel 工作簿中粘贴验证为 3 行 × 9 列，价格 13.00 识别为数值，缺失值保留 —。工作簿关闭且未保存；自动化浏览器与桌面剪贴板间使用显式传递，未将其描述为真实用户端到端操作。
- 在本机 Edge 152 的隔离验收页面挂载真实 Vue 组件，使用虚构六行数据；不连接生产账户。
- 六行 PNG 为 1536×1024。与确认图比对：品牌区 200900 像素、固定表头选定区 49050 像素、说明区 507620 像素均一致；动态文本与已确认字段变化另行检查。
- 真实系统剪贴板写入 image/png，并通过浏览器 Ctrl+V 粘贴事件获得 PNG 文件；未向真实客户发送消息，未验收微信等具体聊天客户端。
- 编辑使旧图片失效，行重排保留正确渠道的手动时效，价格重算更新，商品上下文变化清理编辑；原始价格与时效不被改写。
- 49 行生成 24+24+1 三张，前两张 1536×1729，最后一张 1536×726；最后一张复制通过。
- 人为拒绝剪贴板写入时显示失败并保留图片。
- 延迟样式图片加载，在生成期间切换上下文：旧任务完成后不会恢复旧预览。组件退出时最终 Blob URL 已撤销。
- 实际预览保存区的保存事件、保存拦截、定位校验问题事件通过组件浏览器回归。
- 验证期间没有 POST/PATCH/PUT 等写请求；localStorage、sessionStorage、IndexedDB 均未生成业务图片或记录。生成的验收 PNG 也未落盘。

本次仅本地实现和验证，未提交 GitHub、未部署生产。

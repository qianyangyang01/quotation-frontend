# 客户报价单图片

## 使用与数据边界

报价单列位置拖动或用方向键调整后，自动按当前登录用户 ID 保存在本浏览器。刷新、重新登录、更换商品或打开其他人的历史报价时仍使用自己的列顺序；不同账号分别保存。可点击“恢复默认列顺序”重置当前账号的布局。该偏好只保存列位置，不保存商品、价格、图片或本次临时编辑，也不跨浏览器或电脑同步。

在“报价单预览与保存”中的“客户报价单”区域编辑报价内容；表格最右侧点击“＋ 新增列”，在新列头填写数量后带出各渠道价格。点击“预览报价单”，再“复制报价图片”到聊天窗口。

“复制报价数据”复制同一展示模型的英文表头和全部渠道（Tab 分列、换行分行），可粘贴到 Excel / WPS。美元保留两位小数及 `$`，缺失显示 `—`；不包含内部渠道说明、成本、人民币、成交结果或底部条款。数据复制不要求先生成图片，使用当前全部字段和价格编辑；图片分页时仍一次复制全部行。

“我的报价记录”和“报价记录”详情右下角都有图片、数据复制按钮。图片按钮打开相同报价单预览后再复制；数据按钮直接复制。两者共用当前详情内的临时编辑，关闭图片弹窗后释放 PNG，时效文字编辑保留至关闭详情或记录上下文更新。署名使用记录业务员，日期默认当天。仅使用保存的 quoteOptions / 历史指定报价快照，不查询当前运价、不用成交价替换报价、不补算缺失档位；旧记录没有自定义数量时表头显示 Custom。

- 国家使用简称，英国在客户报价单中显示 UK；原始国家及 GB 代码不变。
- 运输时效来自对应渠道；支持补填、调整及恢复。缺失显示 `—`。
- 处理时间默认 `1-2 days`，允许修改；报价单标题、署名、日期、序号、国家、物流商、时效、美元价格和四条说明均可编辑。组合报价使用 set/sets。
- 同一国家、物流商的多条渠道仍分别列出。编辑表保留来源描述用于区分渠道和区域，客户图片不包含这些内部信息。
- 展示文字编辑仅影响当前报价单。点击正式保存时，将数量和客户价格随报价记录保存；不覆盖系统原价、物流数据或报价草稿。修改国家/物流商名称属于展示调整，不切换实际计价渠道。
- 每张最多 24 条渠道；超过时分图，序号连续，每张重复表头，完整条款只出现在最后一张。切换后逐张复制。
- 复制失败会保留预览并明确提示，可用浏览器右键“复制图片”；不自动下载。

**生成的客户图片只存在于浏览器内存中。** 不上传、不写数据库、不写 localStorage/sessionStorage/IndexedDB、不建立图片历史、不自动下载。
修改、源数据更新、切换上下文、组件退出时撤销旧 Blob URL；取消中的生成结果不能重新成为可复制预览。
`src/assets/quote-sheet` 是固定版式素材，构建时发布一次，体积固定，不随每日客户报价数量增长。

## 版式与接入

确认图是 `codex-clipboard-7957711a-ba27-4a8a-b9f7-d931f4c30548.png`。六行基准图为 1536×1024。
默认四档、六行仍以原图 1536×1024 为基准。固定 Logo 使用原素材；超过四个价格列时每列增加 144 像素画布宽度，十列为 2400 像素，基础列和字体不缩小。数量表头、手动标题和修改后的四条说明使用 Canvas 排版；默认四列未改说明时继续使用原图说明素材。页面可缩放展示完整图片，复制保持原始 PNG 像素。
绝不导出示例姓名、日期、金额或 SAMPLE DATA 页脚。

`customerQuoteSheet.ts` 负责独立展示模型及转换；`customerQuoteSheetRenderer.ts` 负责 Canvas 和内存 PNG；`CustomerQuoteSheet.vue` 负责编辑、预览、复制和取消过期渲染。
`QuotationPreviewSave.vue` 接入客户预览，保留内部基本信息和正式保存校验。
`quotationRecordQuoteSheet.ts` 将历史快照转为相同展示模型；`QuotationRecordCopyActions.vue` 接入两个记录页面共用的详情组件。`customerQuoteSheetClipboard.ts` 复制表格文本，剪贴板拒绝时显示失败，不误报成功。
云速递的英文品牌按其官网 https://www.sfydexpress.com/ 映射为 SFYD Express，与云途 YunExpress 区分。
其他三个矩阵原有 Excel 文本复制不变；沿用当前生产版本的 quotationRowsSignature 完整行签名，已有三种模式的时效变更回归测试覆盖。

不新增 API、数据库字段或图片存储服务。无法识别国家简称或物流商英文映射时给出具体提示，不猜测其他物流商名称。

## 系统报价与客户报价（2026-09-12，本地新增）

新建记录时，在现有记录 JSON 中保存 `systemQuantityQuotes`（不可变的系统价格快照）、`sheetQuote`（首次报价单客户价格）、`customerQuote`（最终客户价格）。没有后台改价时使用报价单价格；后台保存后使用最后保存的客户价格，其他未改数量保留原客户价。图片仍只在浏览器内存生成。

两个记录列表的“报价差异”统一比较原始渠道 ID 与数量，不按名称或行号匹配。没有金额变化显示“客户报价＝系统报价”；多档改价时，选件数最少的已改价档位，不受列顺序影响。同一数量涉及多渠道时取记录中的第一条，悬停提示渠道，明细保留所有渠道与数量。新增数量没有历史系统价时显示“无系统基准”，不推算基准。

明细允许记录所有者编辑客户价格、恢复系统价并保存；保留修改人、时间和前后价格历史。系统原价只读。复制图片与数据使用最终客户价格。按本轮确认，详情移除“客户成交结果”卡片、重复的“查看全部国家与渠道报价”按钮和底部成交处理入口，直接通过“编辑客户报价”修改金额；国家与渠道仍可从顶部页签查看。已有成交数据与状态保留，客户改价不会自动改变成交状态。

金额保存通过已有 POST/PATCH 接口，PATCH 使用 `_version` 并保留原 owner 权限。服务器拒绝覆盖系统快照及首次报价单快照，校验最多 10 列、唯一正整数数量、完整渠道集合、非负金额和两位小数。历史缺失 Custom 数量以内部 0 表示，不伪装成 1 件。客户端阻止重复保存；旧版本冲突保留输入供核对；切换记录和同记录新版本到达后均丢弃过时响应。

本地验收见 [customer-price-comparison-20260912.md](customer-price-comparison-20260912.md)。此新增功能尚未提交或部署。

## 右侧新增数量列与页面滚动（2026-09-12，本地待发布）

- 价格列总数 1–10；数量为正整数，拒绝空白、重复、负数、小数及超出安全整数范围的输入。可删除任意价格列，至少保留一列。
- 现有数量沿用当前矩阵/历史快照价格；新增数量在当前报价页调用同一 `quantityCostBreakdown`，覆盖单品、组合、国家、区域、渠道财务规则。无可用运价显示 `—`，可手填美元，金额最多两位小数。
- 历史记录不具备原始完整计价快照时，不用当前运价补算：已有数量直接带价，新增数量手填。缺失数量的旧 `Custom` 列保留原价格；一旦填写具体数量，不假定旧价格属于新数量。
- 价格手动修改按原始渠道稳定标识与数量关联；修改数量、删除列后不会挪用旧手填值。来源价格重算清除手填价格；价格上下文变化保留数量列，切换商品/组合/报价模式重置本次全部编辑。
- 数量价格列可拖动列头手柄排序，也可聚焦手柄后按左右方向键；整列价格随数量移动，预览与 TSV 同步采用该顺序。
- 新增后自动聚焦列头并向右滚动，“新增列”固定显示在右侧。表格左侧序号、国家、物流商固定，价格区横向滚动。
- 下滚超过 500 像素显示右下角“回到顶部”；尊重减少动态效果设置。在报价记录对话框内回到对话框顶部，不滚动背后的页面。
- 本轮验证详见 `docs/qa/2026-09-12-inline-quantity-columns.md`。只修改本地工作区，未提交或发布本轮功能。

# 移除普通报价自动草稿

## 行为

- 普通报价仅在点击保存后提交正式记录。输入仅保留在当前页面，不再自动写入、恢复或删除普通服务器草稿。
- 刷新/关闭页面使用未保存提醒；切换模块可以继续编辑或放弃输入，不会先等待草稿网络请求。
- 普通报价不显示草稿状态、冲突处理和重试草稿保存按钮。保留清空当前输入和工作区加载失败的重试入口。
- 再次发起仍带入历史报价条件，并按当前资料计算；不自动写普通草稿，不更改原历史记录。
- 撤回编辑仍恢复并自动保存关联原单的内容，保留版本冲突保护、原单号、重新提交和明确取消流程。
- 旧普通草稿不批量清理。仅当用户主动撤回报价时，在账户锁和同一事务中复用旧普通草稿行；已有撤回编辑仍阻止再次撤回。失败则回滚报价、审核与旧草稿；审计记录是否替换旧普通草稿。

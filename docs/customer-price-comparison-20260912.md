## 范围与规则

- “我的报价记录”和“报价记录”共用客户报价对比与编辑组件，保留原记录列表结构和成交结果处理。
- 客户价格优先级：后台最后保存 > 首次报价单客户价格 > 历史系统价格。局部编辑不重置其他档位。
- 比较按原渠道 ID 和数量，区域不同或同物流商不同渠道不合并。
- 列表无差异显示相等；多列改价显示最小已改数量，所有差异在明细查看。
- 原系统价及首次报价单快照不可覆盖；未知系统基准不推算。
- PNG 仍不上传、不中转存储；数字快照随现有报价记录 JSON 保存，无数据库迁移。

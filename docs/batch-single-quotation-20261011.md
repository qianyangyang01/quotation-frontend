# 独立批量单品 SKU 报价

本地实现，尚未提交、推送或部署。工作分支 `codex/batch-single-sku`，基于 `9774ba69865c5d52d9a196d535c1d94fdd978bfc`。主项目已有未提交工作未改动。

## 使用

在普通报价页点击“批量单品 SKU 报价”，或从报价记录页进入“批量单品报价记录”。新功能地址 `/quotation/batch-single`。

1. 粘贴 SKU，每行一个，最多 50 行。格式错误和重复行显示原因，不会悄悄截断。
2. 在首个 SKU 上设置客户、采购阶梯、佣金、国家和具体渠道。仍使用现有报价工作台及 JerryFulfillment 报价单。
3. 点击“应用条件并生成批量报价”，逐个查询采购资料、独立计算。新增的数量列应用到整批，各 SKU 的重量与价格分别计算。
4. 有错误的勾选项阻止保存。可以调整后重新生成，或明确取消勾选异常项。
5. 合并为一张报价单，可复制表格、预览、复制或下载图片，点击保存后在独立批量记录中查询历史快照。

当前范围：单品、具体渠道；不支持渠道平均行。最多每 SKU 100 条渠道、整张 500 条明细、请求 4MB。长报价单图片会分页。未保存内容只保留在当前页面。此批量记录没有接入原报价的审核、成交、撤回和统计流程；本次不实现此前已撤回的异常审核通知方案。

## 隔离边界

- 新页面按路由异步加载，内部错误被页面边界处理；普通页面仍有全部原报价模式。
- 复用计算器只增加默认关闭的 `batchCapture` 开关。启用时只捕获报价和展示快照，不调用原报价保存接口，不加载或写入撤回草稿。
- 使用独立 `/api/v1/batch-single-quotations` 接口、`batch-single-create` 幂等命名空间和 `batch_single_quotation` 表。
- V60 只创建新表及索引，不修改历史报价数据，也不更改过去的迁移。
- 保存时逐 SKU 执行现有提交校验、价格验证、资料就绪和物流版本校验，再核对报价单中的 SKU、数量列、渠道标识及价格。任一项失败则事务整体失败。
- 所有人只能查看自己的批量记录；具有 `allRecords` 权限者可查看全部。新增记录没有修改、删除接口；重复同一请求返回原快照。
- 隔离不意味着独立运行一个计算服务：采购、财务、物流基础资料和现有计价函数仍共用，已有基础设施故障仍可能影响报价。新功能自身不会覆盖普通报价数据。

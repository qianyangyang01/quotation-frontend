# 快驴欧洲小包特货

新增“快驴｜欧洲小包-特货”，仅原表中的欧盟27国，69个重量档和138个价格字段。渠道归入保健品，免税、不另加关税，报价渠道名旁显示“可发种子”。英国、挪威、瑞士、塞尔维亚不导入本渠道，既有美国渠道独立保留。

2026-11-11用户明确确认：欧洲没有时效就不写；马耳他按价格行最高20kg，覆盖须知2kg限制；罗马尼亚没有额外手续费，只使用价格行的公斤价和挂号费；重量向上进位到整克，公斤运费加一次挂号费后合计向上取整到人民币元。各国首重按各自价格行读取，不沿用美国1g首重。

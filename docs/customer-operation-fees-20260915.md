# 客户操作费与采购类别统计

日期：2026-09-15。范围：本地实现与验收，尚未提交或部署生产。

## 业务规则

- 报价条件移除手动“产品品类”。统计和报表按 SKU 对应的采购类别归类；采购类别为空或采购商品不存在时归“其他”。组合 SKU 同类别时保留该类别，混合类别或含无类别商品时归“其他”，每张报价不重复统计。
- 客户名称可搜索并从下拉列表选择，也可手动输入。只有明确选择财务客户才绑定操作费；手动输入同名客户也不收费，键盘输入后直接回车不会自动选择客户。
- 财务新增“客户操作费”，维护客户名称、美元金额和启用状态。每张订单收取一次，直接加到原报价，不参与客户等级系数，也不按件数或套数相乘。
- 单品、组合 SKU、常用国家、指定国家和模板报价沿用共用计价函数；每个数量列单独代表一张订单。例如原报价分别为 10、20 美元，操作费为 1.25 美元，则为 11.25、21.25 美元。
- 最终金额保留系统既有 0.05 美元向上取整。例如 10 美元加 0.01 美元操作费最终为 10.05 美元，财务页面有说明。
- 客户报价图片与复制数据使用包含操作费的最终报价；客户图片不新增内部费用明细。报价记录内部概览可查看当时保存的操作费。

## 影响模块与保护

| 模块 | 调整和保护 |
| --- | --- |
| 财务 | 使用既有 finance-settings 接口、权限和版本校验；业务角色可读，不可写；重复保存受保护；并发旧版本返回 409，保留用户输入。 |
| 报价 | 选择或手动输入客户会刷新报价缓存。财务改名、改费、停用或删除后，旧设置不能继续保存新报价。 |
| 草稿 | 保存并恢复明确选择的模板标识；旧草稿无该字段时视为手动输入。仅放行顶层模板标识，仍禁止旧客户主数据字段、敏感字段和 Data URL。 |
| 正式保存 | 后端核对客户模板、名称、启用状态及费用快照；在报价事务中读锁财务配置，避免保存期间改费造成数据错配。 |
| 历史记录 | 保存客户操作费快照，之后财务改费不会重算旧报价；历史记录缺少快照仍正常显示。 |
| 统计 | 不再采纳旧手填品类。分页读取完整采购目录，避免只加载前 500 个 SKU；采购读取失败时禁用类别统计和导出，不误归“其他”。 |
| 采购 | 不再把商品名称充当缺失类别；采购价格、重量、税点逻辑不变。 |
| 物流与税费 | 原运费、整单重量、关税、附加费、客户等级系数计算不变；公司操作费最后叠加。 |

未新增数据库表或迁移；财务客户列表存入现有财务 JSON 配置，草稿和报价快照使用现有 JSON 字段。

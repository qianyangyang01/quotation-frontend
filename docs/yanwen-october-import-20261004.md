# 燕文十月报价表导入修复

新版原表把产品号与生效日期放在同一个单元格（例如 `产品编号：440\n生效日期：2026-09-29 09:00`），并在 `参考时效(工作日)` 表头声明单位。旧解析器只接受独立的“产品号”标签和带“天/工作日”的时效值，导致产品代码错误和缺失时效。追踪渠道的国家要求区域还会被沿用价格列读取，把芬兰不通达邮编误认为重量。

修复识别标题区内的产品号、产品编号、产品代码，支持同行文字及相邻单元格。只在时效列明确声明天数单位时接受不带单位的完整起止数字；错误产品号、冲突代码、倒序或含糊时效仍不放行。燕文价格使用说明和国家维度具体要求结束前一个价格区，后续真实价格表头仍可开启新价格区，原始说明证据保留。

导入创建草稿失败时保留原始校验问题和真实错误数。已选择替换但新数据有错误时，明确说明旧稿已保留。未完成版本对比的渠道显示“尚未完成对比”，不展示虚假的零变化计数。

验证包括旧版燕文布局回归、错误产品代码、含糊时效、邮编说明隔离，以及可选的生产原始单元格证据重放。证据重放逐条检查国家、分区、计价方式、公斤价、每票费、重量边界和最低计费重量，并对指定导入批次的七个受阻渠道生成待审恢复计划。恢复计划按物流库和唯一渠道定位，包含旧稿、正式版本及批次内容前置条件。

生产恢复仅新增待审核版本并终止相应旧稿，保留来源文件哈希、原始单元格证据哈希和审计记录。不得自动发布物流价格、修改财务设置或重算历史报价。执行时使用事务及内容前置条件，并核对报价、审核、模板、报价草稿、财务、物流渠道及全部正式物流版本的指纹保持不变。

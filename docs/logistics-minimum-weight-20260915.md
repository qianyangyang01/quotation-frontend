# 最低计费重量自动补重

## 规则与范围

- 以原表 `最小计费重量(KG)` / `minChargeWeightKg` 为准，按国家、渠道、分区和对应重量段取值。
- 先按 `max(整票含包材实际重量, 最小计费重量, 明确配置的起重)` 得到计费重量，再匹配价格段，计算公斤运费并加一次每票费。
- 单品多件、组合商品先合并成整票，再补足最低重量；商品资料、人工重量不被改写。
- 明确的最低计费重量允许低于首档下限的包裹补重后匹配首档；不补入上限之外或未覆盖的价格间隙。
- 暂未擅自把所有空白设成 30g，也未把原表首档下限自动视为起重。未配置值当前仍按原有逻辑处理，28 个渠道部分国家的空白口径等待用户确认，尚不能宣布所有渠道的数据已齐备。
- 最低重量为负数或超过该价格段上限时拒绝计算。后端比较同档规则时把最低计费重量纳入判断。
- 海关按重量规则继续使用整票实际重量，物流补重只影响运费。
- 标准模板的 `startWeightKg`（起重）和 `minChargeWeightKg`（最小计重）均进入计算，取较大值；异常数值和相互冲突的计费标准拒绝报价。

# 组合报价按 SKU 选择采购阶梯

以线上 quotation-2026.09.28-09（c246306a）为基线，组合明细每行独立选择采购阶梯。单品保留原入口，新增组合行默认阶梯1。旧记录未保存行档位时沿用原统一档位。

每行的 `purchaseTier` 同时用于采购成本说明、组合成本、矩阵重新计算、保存快照、撤回编辑和再次发起。数量修改、重新查询、单品/组合切换不会覆盖其他行档位。缺档延续现有回退逻辑，并明确显示实际采用的档位。

国内运费平摊使用 Decimal 除法，保留不足一分钱的单件运费，不在平摊时提前取整。无数据库迁移，不重新计算历史记录，不改变审核、处理或成交状态。保留线上普通包材每50g加1g、特殊包装、佣金、平均报价及报价单能力。

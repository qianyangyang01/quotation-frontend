# 移除指定国家与渠道报价入口

## 变更范围

- 开发基线为近期模板精简版本；发布前已合入当前生产基线 `b29d71c68520d6088993ed80e553b430ae008cef`（`quotation-2026.10.04-03`），保留物流加载优化；未混入桌面主目录的其他未提交内容。
- 新报价仅保留“快速报价”和“我的报价模板”，入口改为两列，保留原有默认进入模板的行为。
- 快速报价支持全部国家、渠道搜索及按区域选择。清单存为模板、报价预览删行、复制、价格编辑、保存和实时资料刷新均改为使用剩余两种模式。
- `QuotationMatrix.vue` 仍被模板使用，保留共用组件，不删除模板的渠道选择功能。

## 兼容与数据边界

- 恢复旧 `specified` 编辑输入时，将其 `specifiedSelections` 转为 `commonSelections`，保留渠道标识、国家、同渠道的不同区域、首选渠道及自定义数量。
- 迁移只采用原来当前模式的清单，不把未启用模式的暂存选择合并到报价；空清单不会回退到其他模式的清单。
- “再次发起”兼容 `quoteOptions` 和旧 `specifiedQuotes` 两种历史格式，进入快速报价并沿用现有按当前资料重新计算、校验授权的流程。
- 撤回编辑的草稿恢复、冲突处理及下一次草稿保存继续使用现有版本前置条件与来源报价标识。
- 普通报价不保存/恢复服务器草稿的既有规则保持不变，不因本次兼容重新启用。
- 历史记录的 `matrixMode`、`specifiedQuotes` 和相关数据类型继续保留，用于详情、复制、导出、统计及历史快照读取。没有批量改写历史价格、审核、处理或成交状态。
- 后端草稿接口接受保留的兼容字段；本次无需后端修改或数据库迁移。

## 验证

- 报价组件、报价页面、报价服务及历史记录相关回归：61 个文件、696 项通过。
- 后续补充旧 `specifiedQuotes` 再次发起且原价格/成交/确认状态不变的用例；对相关两个文件复测 39 项通过，总计覆盖 697 项。
- `vue-tsc -b`、Vite 生产构建、变更文件 ESLint、`git diff --check` 通过。
- DOM 测试验证只有两个入口且均可切换；兼容测试覆盖单品/组合、多个区域、旧渠道标识、空清单、重复迁移和不混入其他模式选择。
- 发布仅更新前端，后端、解析器和数据库保持 `quotation-2026.10.04-03`。发布后的版本、备份、回滚、CI 和只读验收证据保存在对应 release-packages 版本目录。本地测试不代表生产登录验收。

# 报价佣金阈值

- 基于生产 quotation-2026.09.17-04；阈值默认 1，由当前报价人填写，仅作用于自己的报价。
- 原最终美元报价（含等级、税费、附加费、客户操作费及原取整）除以阈值，再向上取整到 0.05。人民币由最终美元换算；成本、税费字段不变。6 / 0.95 = 6.35。
- 数值必须有限且 0 < threshold <= 1；无效输入原样保留，停止草稿提交并阻止生成、复制、保存有效报价；修正后继续自动保存。
- 草稿和正式记录 JSON 增加 commissionThreshold，旧请求/旧草稿缺字段视为 1。旧草稿相同语义重复保存不推进版本。正式历史金额不回算，无数据库迁移。
- 前端统一从原始报价计算，矩阵上下文包含阈值；已选渠道及客户表系统价随之重算。客户手动改价沿用现有机制，不再除佣金。客户输出不显示阈值，内部记录详情和计算规则显示。
- 后端验证阈值范围、美元 0.05 格式与人民币换算；沿用原物流校验及权限，不增加后端完整报价重算引擎。
- 回滚应用需注意：新增草稿字段不受旧后端白名单支持，旧前端也不理解非 1 阈值。优先向前修复；紧急回滚先留存新版本草稿和报价快照，不自动删除字段或重算历史金额。

验证包含：十进制边界、无效值、单品/组合全部数量、含税/免税/附加费/操作费、无重复除佣金、客户手工价保存、草稿账号隔离与兼容、正式提交后读取。

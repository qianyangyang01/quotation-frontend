# 客户报价单临时商品图片

在客户报价单选择 1–4 张 JPG、PNG 或 WebP（每张至多 10MB、4000 万像素），可替换、移除或隐藏。没有图片时不增加图片列。有图时在 No. 与 SKU 之间增加 Product 列，当前商品或组合的全部渠道共享一个单元格；分页图片每页各展示一次，保持比例、不裁剪，单条渠道也保留足够图片高度。

图片仅为组件内存中的本地 Blob URL 和已解码图片，不调用上传接口，不写浏览器持久化存储，不进入报价模型、草稿、正式记录或价格快照。文字复制保持原有 TSV。图片复制使用合成后的 PNG。更换商品、报价重置、切换账号/记录、组件卸载时释放 URL；刷新后需要重新选图。普通价格计算变化保留当前图片。读取失败保留之前的图片；晚到的旧读取结果被释放，不覆盖新商品。

无后端、权限、数据库、财务物流或采购修改。复用现有报价页面及记录组件的访问权限。

验证：新增本地图片读取、资源释放、失败和超时、非法格式和大小、图片合并单元格、快照/复制隔离、切换商品和迟到读取、分页绘制与比例测试。完整前端 837 通过、2 跳过；lint、vue-tsc、生产构建通过。本地真实浏览器验证多文件选择、合并列生成、隐藏预览和刷新清除。

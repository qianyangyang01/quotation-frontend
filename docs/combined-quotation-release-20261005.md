# 组合报价、分区展示和记录图片合并发布

本次同一版本包括三个已确认的改动：

1. 同一 SKU 可按单套数量成套报价，例如单行数量 3 表示同款三件套。
2. 报价单新增澳大利亚分区显示开关，按报价员记住本机选择，预览及复制结果同步隐藏或显示分区标签。
3. 报价单图片通过正式 PostgreSQL/MinIO 资产接口保存；报价记录再次预览或复制时恢复图片。旧记录保存过的商品资产图可作为回退，过去未持久化的临时图片无法恢复。

图片仅持久化资产引用，加载失败会提示重试；已有报价和草稿引用的图片不会被未引用资产清理逻辑回收。历史价格和审核/处理/成交状态不批量修改。

# 非常用国家第二轮前端优化

基线：生产 `quotation-2026.09.16-11` / `65d9e47`。

## 已确认的重复工作

- 指定国家/模板模式传入 `activeRegionalQuoteRows`，直接调用 `expandedCountryQuoteRows`。
  对无分区国家，每次调用都执行 `excelQuoteRows`；表格摘要、已选行、推荐、弹窗反复读取时没有国家级缓存。
- 同一已验证物流版本添加国家仍替换全局索引、重新赋值财务政策并递增全局规则代次，导致既有国家报价失效。

## 本轮变更

- 指定/模板复用 `allRegionalQuoteRows`，普通模式非澳洲国家也复用它；澳洲普通模式保持当前分区，指定/模板保留所有分区。
- 同版本仅使新增国家的计算缓存失效。全量刷新、版本变更仍全局失效；Vue computed 继续跟踪所有实际读取的价格输入，不使用易遗漏字段的手工价格缓存键。
- 财务政策在同版本增量加载时不重复归一化；渠道可用性仍实时与已加载物流规则求交集。正式财务刷新机制不变。
- 未变化的规则对象保留索引；变化的规则重新建立索引。区域索引只清理涉及国家，国家代码/名称使用已发布目录及历史别名对应。
- 不改后端、数据库、物流正式价格、授权条件或保存校验。无预加载全世界、无额外后台请求。

## 验证与计时边界

- `quotationCountryRows.test.ts` 从真实报价页提取函数和缓存声明，验证 100 次重复读取仅一次试算；新增荷兰不使美国失效；重量、财务参数、版本变化触发刷新；澳洲两类模式语义保持。
- 矩阵交互测试覆盖两种模式的搜索/打开缓存复用与计价输入变更。
- `.channel-dialog` 提供 `data-load-ensure-ms`、`data-load-dom-ms`，仅存当前弹窗本地计时，不持久化、不发送遥测、不包含业务内容。
  ensure 包含排队、清单校验、规则下载/缓存、合并应用，**不是纯网络耗时**。
  DOM 计时到 Vue nextTick 完成，**不是浏览器绘制/P95，也不包含自动化工具调用开销**。
- 本地计算次数和回归结果不等于生产速度。发布后仍需记录首次/重复打开荷兰、西班牙等国家的 DOM 时间与服务端请求耗时，并检查价格、既有选择、切换 SKU、保存等待和错误重试。
- 未进行多人 HTTP/浏览器并发验收，不声称已达到多人生产 P95 目标。

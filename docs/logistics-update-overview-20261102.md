# 渠道价格更新概览

在“渠道价格变动”页右上角增加“更新概览”按钮。点击打开独立弹窗，查看当前国家、物流属性和重量下，每批更新涉及的全部系统渠道 / 分区。显示更新前价格、更新后价格、明确的“涨价 / 降价 X.XX 元/票”和涨跌幅。

## 比较口径

- 按同一操作人从第一笔导入开始的固定 4 小时汇总。窗口为左闭右开：08:00 首笔导入，12:00 起的新导入另开一组；后续上传不延长窗口，跨午夜仍按完整 4 小时计算。窗口使用当前物流库全部原始导入元数据，在国家、属性、重量和发布状态筛选前计算，未发布的首笔上传同样作为时间锚点。
- 每组保留原始上传批次，可展开查看导入时间、操作人、来源文件和各批已发布价格；支持“查看该批价格”及“返回整组汇总”。同一渠道在组内多次更新逐次列出，不合并中间价格。按导入时间归组，各行保留实际发布时间；缺少完整导入元数据及回滚版本独立显示。
- 优先比较源版本声明的 `basePublishedVersionId`。旧记录未留该字段时使用该渠道紧邻的更早已发布版本；基准 ID 已记录但缺失时标为不可比，不跨过缺失版本。
- 只比较同一渠道 ID、国家、分区和重量。新增适用价、移除适用价、首次记录及其他不可比情况不伪造零元，也不计入涨价 / 降价。原价为零时展示具体金额，不计算百分比。
- 概览包含当前物流库保留的历史发布记录，包括当前暂不可报价的渠道；归档渠道不在现有价格快照中。渠道名称、物流属性按当前资料展示。
- 延用现有历史计费结果，包含渠道原生固定费，不含财务折扣、关税及其他附加费。筛选属性使用系统属性，不受趋势卡片的重点渠道清单限制。

## 操作

- 初始继承趋势页国家、属性和重量，默认最近一次有记录的批次；不改变趋势页筛选。
- 默认显示有变动及待核对记录，可显示全部、仅涨价、仅降价、仅不变，支持渠道 / 物流商 / 分区搜索。
- 使用原生模态对话框，支持 Escape 关闭并回到触发按钮，背景不能交互，窄屏表格可横向滚动。
- 复用会话快照，打开、筛选、关闭不发起新的价格请求；发布事件与手动刷新仍走原有缓存流程。刷新失败保留旧数据。
- 概览具备独立组件异常边界；渲染失败卸载弹窗并解除模态遮挡，只显示可关闭、可重试的提示，趋势页面与其他工作区继续使用。导出失败仅在弹窗内提示。
- 可下载当前筛选结果的 PNG；超过 25 条自动导出包含分页面 PNG 的 ZIP，避免遗漏长表记录。

## 数据与上线范围

后端 `/logistics/price-history` 只读增加 `baseVersionId`、`importBatchId`，及当前物流库完整 `importBatches` 元数据（ID、创建时间、操作人）。批次 ID 必须有效、属于同一物流库，且该批次 `results` 确实包含该版本；复制版本和回滚不能因继承批次字段而误归组。

无数据库迁移，无发布流程、计费引擎或历史报价写入。上线时需要同时包含前端和后端改动。旧后端缺少批次字段时前端可正常使用，但各版本作为独立发布记录；有批次 ID 而缺少时间 / 操作人时，保留原始上传批次，不猜测 4 小时归组。

实现分支：`codex/logistics-update-overview-20261102`，基于 `2da767a2`。计划发布 `quotation-2026.11.02-02`，部署及线上核验结果另存对应发布包。

## 已完成验证

- 前端相关 13 个测试文件、82 项测试通过，包括固定 4 小时边界、跨午夜、操作人隔离、未发布首笔锚点、筛选稳定、原始批次展开 / 查看，以及金额、历史批次、分区、重量、初始 / 缺失 / 零价 / 回滚、筛选和会话缓存。
- 后端历史价格相关 20 项测试通过，无跳过，包含真实 PostgreSQL 的批次归属、无效 UUID、复制 / 回滚隔离、未发布批次的操作人与导入时间，以及只读快照检查。
- TypeScript 检查、生产构建、新增前端文件 ESLint 和 `git diff --check` 通过。
- Edge 浏览器在 1600 / 1024 / 390 宽度通过按钮、弹窗、批次与重量切换、键盘关闭 / 焦点、PNG / 多页 ZIP 导出检查；无页面异常，无生产 API 请求。
- 实际页面截图和机器报告位于 `artifacts/update-overview/`。截图使用明确标识的本地验收样例，非生产价格。

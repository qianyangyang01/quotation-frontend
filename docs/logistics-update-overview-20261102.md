# 渠道价格更新概览

在“渠道价格变动”页右上角点击“更新概览”，打开左侧批次、右侧单表的独立弹窗。默认全部国家、全部物流属性、仅可比较的涨价和降价；试算重量沿用打开前选择，不修改原页面条件。

## 比较口径

- 同一操作人从第一笔导入开始固定4小时归组，窗口左闭右开，后续导入不延长结束时间。跨午夜仍按完整4小时计算。全部导入元数据先确定窗口，未发布首笔也可作锚点，再筛选已发布价格。无完整导入信息及回滚独立展示。
- 优先使用版本声明的基准ID；旧记录未留该字段时使用同渠道更早已发布版本。明确基准缺失时标为不可比，不能跨过缺失版本。仅比较同一渠道ID、国家、分区和重量，不跨国家拼价格。
- 首次、新增、移除及其他无可比价单列，不伪造零价，不计入涨跌。原价为0显示金额但不计算百分比。同一渠道组内多次更新逐次保留。
- 渠道按唯一ID计数；价格记录按国家、渠道、分区、发布版本计数。包含快照中当前暂不可报价的历史渠道，归档渠道不在现有快照中。名称和属性按当前资料显示。
- 金额沿用历史计费结果，含渠道原生固定费，不含财务折扣、关税及其他附加费。

## 操作和隔离

- 左侧批次卡片支持日期/操作人搜索和每页10批分页；翻页选择该页首批。刷新保留仍存在的选中ID并定位其所在页，无搜索结果清除过期价格展示。
- 顶部分类可查看有涨跌、上涨、下降、不变、新增/移除/不可比或全部。五个涨跌最多国家作为快捷入口，所有国家均可搜索选择。
- 明细每页10/20/50条，改变条件后回第一页。桌面外框固定，批次列表和表格独立滚动；表头、条件、分页保持可见。
- 价格详情保留前后价格、金额、幅度、版本时间、源文件和批次。右侧详情打开时背景不可交互，Escape优先关闭详情并恢复焦点；再次Escape关闭概览回到触发按钮。
- 原始上传批次可展开，支持查看单批价格和返回整组。下载包含全部筛选结果，不受屏幕分页限制；每25条一张PNG，多页打包ZIP，逐条包含国家标识。
- 复用只读会话快照，打开/筛选/关闭无新增价格请求；手动刷新与发布事件沿用原有缓存。刷新失败保留旧数据。独立异常边界使概览失败时仍可使用其他模块，导出失败只在弹窗提示。

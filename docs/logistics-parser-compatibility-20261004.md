# 旧版导入草稿发布兼容性

解析器升级后，批次页面按价格校验结果显示可发布，但计费验收要求草稿解析器版本与当前版本完全相同。9 月 29 日解析器生成的有效草稿因此在发布事务中回滚，结果显示跳过。

将生产者版本识别改为明确的兼容策略：接受当前版本和经核对价格数据结构兼容的 `wanbang-yanwen-express-2026.09.29-v3`。不按版本前缀或日期泛化放行；缺失、未知或未经验证的版本仍阻断。原有基线、价格错误、风险确认、模板与计费引擎校验不变。

批次查询使用同一策略对草稿生成只读的不可发布提示，不修改导入证据。最终验收仍在每个渠道发布事务中检查，失败则回滚该渠道。验收审计分别记录原始 `parserVersion` 和当前 `validationParserVersion`，不把旧草稿伪装成重新解析结果。

回归覆盖已知旧稿完整发布和财务报价就绪、重复发布幂等性、未知版本页面阻断和事务回滚、已知版本仍拒绝真实价格错误。可通过 `-Dlogistics.compat.fixture=/evidence/compat-fixture.json` 在隔离 PostgreSQL 上逐个发布只读导出的 12 份生产草稿（676 条价格）；原始业务数据不进入仓库。

此修复不改写生产草稿、正式价格、历史报价或财务设置。新发布仍由用户审核确认后通过正式发布流程执行。

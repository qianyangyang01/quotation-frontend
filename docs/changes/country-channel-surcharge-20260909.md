# 国家与渠道附加费

## 影响范围
财务附加费详情、设置持久化、单品和组合报价的所有数量档、报价快照与复制导出、后端新报价校验。关税设置保持独立，整单附加费只加入一次，再执行美元 0.05 向上取整和人民币换算。

## 操作
点击国家名称打开该国家详情；渠道按物流商分组，可单独勾选或分组全选。勾选为免附加费，未勾选为收取该国家金额。确认当前国家后，再保存并发布。详情未确认时禁用发布，取消不修改草稿。不同国家独立维护。

## 数据兼容及风险
- 每个国家保存 exemptChannelKeys，使用现有财务渠道完整标识，与普通渠道权限相同。
- 字段缺失表示旧全局规则，明确显示待确认并保留原行为；不会推测各国豁免。空数组表示已确认全部收费。
- 新增国家默认全部收费；实际生效还取决于国家金额。停用或零金额不收费。
- 原全局 provider 数据保留，仅供尚未确认国家兼容使用；历史报价与金额快照不迁移、不重算。
- 渠道目录仅显示该国家可用的渠道。既有失效标识保留以避免静默删除，但不会授权不同渠道。
- 设置继续使用原权限、版本冲突检查及更新事件。后端在创建事务中锁定读取当前附加费并核对快照，拒绝过期或伪造豁免；历史读取、成交维护和已成功幂等重试不重新核算。

## 验证
覆盖国家间隔离、同一物流商渠道区别、空选择、缺渠道标识、旧全局兼容、金额取整、单品组合数量档及导出、详情取消和确认。前端全量测试及类型检查、构建、ESLint；后端财务设置和报价校验定向测试。最终结果见交付消息。

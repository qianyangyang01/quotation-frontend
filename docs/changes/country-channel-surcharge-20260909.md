# 按国家配置物流商附加费

恢复原物流商表格样式：物流商、覆盖渠道、免附加费/不免附加费、删除、添加物流商和搜索。点击国家名称切换该国列表，修改直接进入财务草稿，顶部保存并发布后生效。不再显示渠道复选框。

每个国家独立保存 providers；报价前后端优先使用国家物流商规则，旗下该国所有渠道统一生效。缺少物流商配置时阻止报价，不静默免除。关税保持独立，附加费整单一次，美元取整及人民币换算保持原逻辑。

旧全局配置和已保存渠道级配置保留兼容，不在部署时改写财务数据。国家尚未配置 providers 时沿用原计价；第一次编辑该国物流商时转为国家物流商规则。旧渠道配置中同一物流商若有免收冲突，不自动认定全免，需在添加物流商中明确设置。历史快照和金额不变。

验证包括：原表格按钮、无渠道复选框、国家切换隔离、同商不同渠道统一生效、持久化回载、缺少物流商拦截、后端过期豁免拒绝。沿用原财务权限、If-Match 保存和报价同步流程。

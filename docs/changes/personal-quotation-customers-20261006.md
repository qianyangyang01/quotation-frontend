# 个人常用客户：添加与管理合并

报价员可保存自己的常用客户名称，下次直接选择，减少重复输入。客户下拉区分个人常用客户与公司计费客户，底部只保留一个“个人客户 · 添加与管理”入口。

## 交互

- “我的常用客户”弹窗上方直接输入名称并添加，下方搜索、选用、修改名称、移出；修改和移出确认在同一弹窗内切换。
- 添加仅保存名单，点击“选用”才带入当前报价；名单改名或移出不替换当前已填写名称。
- 保留自由输入。公司客户仍展示操作费；个人客户标明“仅名称”，同名时也必须显式选择公司项才关联公司操作费。
- 保存失败保留输入；重复名称可选用已有项；版本冲突刷新名单后保留未保存名称并使用最新版本重试。
- 使用最近选用顺序；切换登录账号关闭窗口、清空旧名单并忽略旧请求的迟到响应。

## 数据与联动

- 新增 V57，仅创建 personal_quotation_customer 表，按登录用户 UUID 隔离，不接受请求传入归属或费用字段。
- 接口要求报价权限，所有读取、修改、移出、最近使用都校验本人归属；管理员也不能通过该接口访问他人的私有名单。
- 名称长度 120，拒绝空白和控制字符；本人名单名称不区分大小写去重；创建幂等，修改/移出带版本校验，用户行锁串行化并发修改。
- 个人选择复用自由输入事件，清空原 selectedCustomerId；公司选择沿用原操作费配置和明确 ID 绑定。个人名单不写财务设置，其他客户等级、物流、利润规则照常计算。
- 报价、草稿、再次发起仍保存/恢复客户名称快照；不增加个人名单外键，不批量修改历史数据。公司计费客户已有 ID/费用快照逻辑保留。
- 创建、改名、移出写入现有审计；不触发报价审核、优先处理、成交状态变化。
- 保留本工作区此前的优先处理和报价记录工具栏调整。

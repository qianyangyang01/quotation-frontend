# 报价物流属性下拉框跟随财务授权

基于当前生产版本 quotation-2026.09.21-05 / e31cbb0bf8b8887e9d793140540d920e2d370295，在独立工作区完成。

## 问题与修改

报价页原先将系统内置物流属性与财务配置合并，导致财务没有配置的粉末、非液体化妆品、带磁、微敏感也出现在下拉框。现在仅展示财务已启用的属性，保留原有顺序和属性别名处理；以后财务新增或停用属性时，报价页沿用现有配置同步流程更新选项。

按本次财务配置，保留9项：普货、化妆品、保健品、带电、纯电、服装、香水、大货普货、大货带电。

修改仅涉及 QuotationSystemView.vue 的选项生成和 QuotationCondition.vue 的无有效选项提示。系统物流属性定义、解析、计费、财务授权数据和历史记录不变。员工与管理员共用此报价页面。

财务尚未加载或未启用任何属性时不补入默认选项。旧草稿使用未授权属性时保留原值，显示不可选提示，现有表单校验要求重新选择；不自动将历史属性切换为普货或其他属性。

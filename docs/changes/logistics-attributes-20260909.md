# 物流属性：纯电与服装

## 影响范围与实现
- 财务和报价共用属性目录，顺序为普货、化妆品、保健品、带电、纯电、服装，再保留其他现有属性。
- 纯电池作为纯电的兼容别名：财务读取、新配置保存、前后端准入标记、后端渠道权限检查一致归一化。策略 ID、国家及渠道绑定不因改名重建。
- 服装是独立属性，没有默认授权渠道，不继承液体、普货或其他属性的财务策略。
- 液体退出新报价选项；旧策略保留供维护。旧液体草稿回载保留原值，让校验要求重新选择，禁止静默改成服装或普货。后端拒绝旧页面以液体提交新报价。
- 历史报价展示、导出和金额快照未改写；本次没有数据库迁移、生产配置写入或价格变更。

## 异常场景与测试
- 纯电池旧策略可匹配纯电请求，纯电池禁止标记也阻断纯电；避免改名绕过限制。
- 新旧纯电策略并存时，前后端拒绝歧义授权；保存时后端拒绝重复属性，不能自动合并扩大权限。
- 未配置服装渠道时不可用；配置后按国家和渠道生效，停用、其他国家或液体策略不能授权服装。
- 保留旧测试，新增别名、排序、源对象不变、独立服装授权及持久化回载测试。
- 不将物品名称中的“电”或“液体”做全文替换，不改原表证据和历史记录。

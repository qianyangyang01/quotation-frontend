# FOB 分类报价与票据规则

## 行为

- 三类新报价：可报关退税 FOB/EXW（1.08）、可报关退税 CFR/CIF（1.11）、普通 FOB（1.20）。系数只对超级管理员开放，设置合并在财务客户系数区域。
- 前两类按采购阶梯原价乘以 1＋实际票点；已含票阶梯直接使用。票类型或票点缺失时默认10点，并持续提示采购维护对应来源SKU。已明确普票/无票或含票价与实际票点冲突时拦截。
- 普通FOB沿用原10点成本、国内运费和小额订单规则，仅最终报价系数从1.1628改为1.20；不套用退税专票提醒或冲突校验。
- 单条和批量共用后端计价与版本校验。批量异常SKU可单独处理，其他有效行可继续；批量生成先验证全部选中行，避免异常行导致技术报错。
- CFR/CIF分类不新增国际运费或保险费自动计算。

## 其他报价和历史记录

- 单品、组合、女装、试算、仅代发货的金额计算保持原样。FOB系数变更不使这些报价误判为财务过期；汇率及其他实际参与计价的设置仍正常校验。
- 新老财务版本快照兼容。旧FOB报价仍使用保存时的双价格列及计价快照，既有审批流程保持原样。
- 无数据库结构迁移，无采购资料自动回填，无历史报价批量回算或状态更新。

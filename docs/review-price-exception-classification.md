# 报价异常分类

审核人员点击“价格异常”后选择异常类型，说明可选填，再正式提交。分类必选且无默认值；说明留空或仅空白均可提交，填写时最多500字。审核通过与免审无需分类。普通、组合、FOB逐项和旧独立批量报价入口执行相同校验。

类型：`purchase-price` 采购价格异常、`channel-price` 渠道价格异常、`entry-error` 业务填写错误、`other` 其他/原因待核实。旧页面不带分类的新退回请求返回422，需刷新页面填写；已有历史记录不补写、不推断分类。

普通报价的 `priceException` 保存于审核状态及本次审核历史；逐项报价保存在该行审核状态和对应历史。内容包括分类、记录时间、异常SKU、采购数据来源、判定时读取的采购报价人和是否待归属。客户端不能指定采购人，后端按原报价SKU与采购来源解析。组合报价的采购价格异常必须选择实际异常SKU；无采购人或来源不明的记录保留待归属。采购资料以后修改不改变既有审核历史归属。

状态改变沿用审核版本和报价版本校验。分类不改动报价价格快照、采购资料、成交状态和其他商品的审核结果。重新审核保留原分类历史；非异常结论清除当前分类，不删除过去的事件。

本次提供分类采集与详情/历史展示，不含采购排行榜接口或自动通知采购。后续排名应仅选正式提交的采购价格异常事件，按报价ID、异常SKU去重，按当时保存的采购归属聚合。按时间区间统计时使用审核事件时间，不使用报价创建时间。历史未分类及待归属单列；纠正分类需沿用可追溯审核流程，不能直接修改历史事件。不得把前端选择下拉次数或历史未分类记录算作采购异常次数。

# 同一 SKU 多件成套报价

组合报价原先在前端保存条件和后端提交校验中要求至少两个不同 SKU，即使一行商品填写三件也无法保存。现在允许一行 SKU 的单套数量大于等于 2；多个不同 SKU 的组合继续有效。

操作：选择组合报价，查询一个 SKU，将单套数量设为 3。报价单显示 `SKU*3`，报价数量 1 套对应 3 件，2 套对应 6 件。采购成本、国内运费、基础重量和包材重量继续使用现有按单套数量乘套数的计算逻辑。

保留正整数数量、非空且不重复的 SKU、商品名称、重量、成本和主 SKU 顺序校验。草稿、保存快照和再次发起沿用现有结构，无数据库迁移，无历史记录重算或状态修改。

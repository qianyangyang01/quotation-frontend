# 国家物流商税务配置

点击税率设置中的国家，沿用原物流商表格设置免税/不免税，覆盖该物流商在当前国家的渠道。

## 影响与兼容
- 财务页面、tax-settings JSON、报价税费计算、正式报价提交校验。
- countries[].providers 为可选独立配置；缺失继续使用原 providers；空列表表示未配置，不能回退全局免税。
- 新增国家初始化空列表；修改一个国家不修改其他国家或全局旧配置。
- 旧记录快照不迁移、不重算。关税仍是固定 USD/单，附加费独立计算。
- 新配置国家提交报价时，服务器检查物流商税务状态和固定关税金额，拒绝旧配置或伪造豁免。

## 验证
- 前端覆盖国家切换、免税按钮、隔离、旧配置兼容、空配置阻断、序列化回读。
- 后端覆盖非法国家物流商模式及过期免税信息拒绝。
- 无生产数据修改；需发布后登录验收实际保存与刷新回读。

# 渠道平均报价

报价单工具栏的“渠道平均报价”打开配置面板。按国家列出已经加入报价单的全部渠道，勾选同一国家的至少两条可用渠道（不按税费口径或区域筛选），选择普通平均或加权平均，填写客户展示名称和运输时效，点击“生成平均行”。生成后的方案可编辑、移除，也可新增其他方案。

- 渠道列表显示已加入和已勾选的数量；不可用渠道显示原因并禁用，不能静默隐藏。澳大利亚保留区域批量勾选，也可直接选择渠道。
- 普通平均：所选渠道的系统报价之和除以渠道数量。
- 加权平均：各渠道系统报价乘以权重后求和；权重为正数、最多两位小数，合计必须等于 100%。支持平均分配权重。
- 每个数量档位独立计算，使用十进制四舍五入保留两位小数。缺失的系统价格不能按零参与计算。
- AVG 行可单独修改最终客户价。原渠道客户改价不改变平均计算基准。
- “仅综合报价”在客户输出中隐藏参与渠道，“综合报价＋明细”同时输出来源与 AVG。编辑器保留原始渠道以便检查，后台完整版本保留全部来源。
- 修改权重、渠道或计算方式会重新计算该方案的客户价；只修改名称、时效、展示方式时保留客户改价。
- 拖动数量列按数量身份匹配数据。新报价的系统价格或来源变化后，旧平均方案失效并提示重新生成。

## 保存和审核

方案随现有 `customerQuote.averagePlans` JSON 保存，包含稳定方案 ID、来源 option ID、权重、数量、来源系统价格、系统平均价、最终客户价与展示设置。`sheetQuote` 保留首次报价快照，`systemQuantityQuotes` 保留原渠道系统价格，不插入虚构物流渠道，不新增数据库迁移。

服务端对来源身份、可用性、国家、数量、权重和系统价格逐项校验，再独立计算平均结果。修改已有报价使用保存的系统快照，不读取当前物流价格。旧客户端价格补丁省略方案字段时保留原方案；显式空数组表示移除方案。

主动修改 AVG 客户价、方案来源或权重，沿用已有客户改价的确认与财务审核流程；纯展示修改不重置审核。列表价格差异、数据库筛选、对比面板、改价历史和复制数据均包含综合报价。

## 验证和交付范围

单元与组件测试覆盖十进制计算、缺价、权重校验、来源变更、数量重排、保存回显、客户改价、展示切换、图片数据模型和文本复制。Java 测试覆盖快照校验、防止伪造源价、兼容旧客户端、确认及审核变化；PostgreSQL 集成测试覆盖 AVG 价格差异筛选与跨页查询。

本功能需要前后端配套发布。开发验证使用本地组件页面和隔离测试数据库；没有创建或修改生产业务记录。截图、构建及测试日志位于工作区 `outputs/channel-average/`，不进入发布包。

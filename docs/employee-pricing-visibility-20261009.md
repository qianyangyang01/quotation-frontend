# 报价成本展示权限

本次按用户确认的范围，仅调整页面、详情和导出。浏览器仍读取计算所需原始数据；不构成接口级成本保密，服务端报价计算与接口脱敏不在本次范围内。

## 权限与联动

- 使用登录会话的实际模块权限，不按角色名称猜测权限。没有登录信息时默认隐藏。
- `purchase`：采购单价、票点、国内运费、产品成本及成本快照。
- `logistics`：物流成本、运费试算金额及选用渠道后的运费提示。
- `finance`：FOB 报价乘数；完整计算规则与利润需同时拥有以上三个权限。
- 普通员工仍可选择客户等级、采购阶梯、渠道、数量及重量，查看最终售价，保存报价、查看本人历史、处理成交和复制客户报价单。
- 单品、组合和 FOB 当前报价，以及普通/FOB 历史详情同步控制。组合历史详情中的独立商品快照也按采购权限隐藏采购价和国内运费，覆盖我的记录与全体记录。组合表隐藏成本后重新排列列宽。
- 普通员工的两种历史复制操作都输出允许展示的报价字段；同时过滤文本与 HTML。采购权限可额外带出产品成本摘要；完整对账需具备全部成本及财务权限。
- 报价记录、报价预览的 CSV 导出不含普通员工无权查看的成本列；预览中的采购均价也按采购权限控制。
- 角色或权限在当前会话变化时，显示立即响应；复制/导出在生成内容时重新取当前权限。
- 手动报价试算保留用户自行填写的成本输入，它不展示采购库成本。客户等级名称、财务汇率、用户填写的佣金阈值及客户报价保持现有行为。

## 数据边界

仅条件渲染和导出选择，不删改计算对象、提交载荷或历史快照；报价金额、采购/物流资料维护、客户系数配置、报价保存、撤回再提交、审核及成交逻辑不变。无数据库迁移。

## 验证

- 员工、采购、物流和拥有全部管理权限的会话展示；动态撤权、未登录默认隐藏。
- 单品/组合重量、采购阶梯操作保留；最终报价一致，源数据无变更。
- FOB 查询、1 元加价、历史成本隐藏及保存快照保护。
- 两个复制入口、文本/HTML、CSV 列与金额过滤，管理员原明细保留。
- 全量前端：213 个测试文件通过，1701 项通过；14 文件/16 项既有跳过。类型检查、ESLint、生产构建通过。
- 本地真实组件页面分别使用员工/管理权限验收；生产浏览器验证需单独记录真实登录账号范围，不将本地权限夹具称作生产员工登录验收。

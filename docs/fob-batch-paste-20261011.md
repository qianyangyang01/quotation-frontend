# FOB 批量粘贴报价

发布候选：`quotation-2026.10.11-01`。用户已授权提交和部署；实际发布状态以服务器 manifest 和验收证据为准。基于线上前端版本 `quotation-2026.10.09-13` / `0ee3af6b34c0f2eb011a4b7112be3a5ae357c612` 建立独立工作区。

## 操作和异常处理

- 原 FOB 查询栏仅增加“批量粘贴报价”按钮。支持一列 SKU、同一单元格内 SKU 和数量、Excel 两列粘贴；每次最多 100 个非空行，超限整体提示，不截断。
- 指定数量模式必须补齐数量，未填不默认 1。全部阶梯模式允许不填数量，沿用单品 FOB 阶梯与小额订单规则。
- 原行号保留。SKU 未找到、数量格式、起订量、下单倍数、重复行、权限/网络/超时、采购包邮与正数运费冲突分别提示。同 SKU 不同数量可以并存。
- 查询最多 4 个并发请求；相同来源和 SKU 在同次查询复用请求。重新查询、关闭弹窗会取消旧查询，避免旧响应覆盖新结果。
- 仅生成已选且有效的行，底部明确列出待处理和未选数量。异常行继续保留，并可导出异常清单。
- 蓝色价格列显示当前数量最终报关/不报关价格。成本明细按既有角色权限折叠显示，不进入客户报价单。

## 价格和快照

使用既有 FOB 价格函数与服务端 `FobQuotation.prepare`；没有新增折扣或成交底价政策。生成预览调用只读业务接口 `POST /quotations/fob/preview`，保存再逐商品复核当前来源版本、汇率、规则和所有价格。任何一个商品冲突都阻止整份保存，无部分保存。

一次生成一条 `schemaVersion: 2` 报价，包含每项版本 1 快照、采购来源原始数据及合并展示数据。保存仍用原有幂等键和事务；网络重试不会重复创建记录。预览接口不创建报价、草稿或审计业务写入。

已保存报价从快照展示、复制及导出，不读取最新采购资料重新计算。再次发起带回全部商品及各自采购来源，查询新资料后创建新报价，原记录保持不变。

## 模块联动

- 报价记录：按任意一项 SKU 可查整单，详情显示全部商品和最终价，不用第一项单价表示整单。
- 成交登记：选择实际成交 SKU 和报关方式，验证逐项金额及汇总；不会把全部商品误计为成交商品。
- 统计/CSV：批量报价纳入报价数和 SKU 数；无单一系统单价，报价金额汇总明确排除批量单。CSV 写入逐商品最终价，不写虚假零价。
- 导出：Excel、浏览器打印/另存 PDF、每 20 行一页的 PNG。沿用现有单品报价图片布局，批量使用独立布局。
- 财务审核、记录权限、采购引用保护仍走现有后端流程。成本 UI 隐藏遵循既有权限，未改动既有 API 字段权限契约。

# 报价模板同步与渠道移除

## 入口与权限

- 在“我的报价模板”工具栏的“管理我的模板”右侧显示“同步模板”。
- 同步入口和接口仅允许具备报价权限的超级管理员使用；财务即使具有相同业务权限，也不能跨账号同步模板。
- 来源与接收人来自服务器实际启用且拥有报价权限的账号，显示姓名和账号以区分身份，不能同步给来源本人。

## 同步规则

- 勾选来源模板和接收人员，填写名称前缀，预览最多新增数量后同步；默认前缀为来源姓名首字加 `-`。
- 完整复制模板内容，替换名称、数据库归属和 payload 的 ownerAccount/ownerName/ownerKey，生成新 ID、时间和版本。
- 同名模板跳过，其他模板新增；不会覆盖已有模板。结果按接收人展示新增、跳过及对应模板明细。
- 每次同步是一次性复制，副本独立维护，来源后续更新不会自动传递。
- 账号按固定顺序加事务锁，来源模板带版本校验及读取锁；两个管理员重叠同步不会重复创建。同一个网络重试保持同一幂等键。
- 单次最多200个来源模板、200名接收人和10000个副本；来源过期、人员状态变化或任一模板无效时整批回滚。
- 每个新增副本记录 `template.sync`，批次结果记录 `template.sync.batch`；原始模板保留。

## 明细移除与联动

- “管理我的模板”的已保存模板明细，每条国家/区域/渠道右侧显示“移除”。创建预览和确认差异等只读明细不显示此按钮。
- 点击后立即提交版本校验更新；成功后删除对应行、更新国家和渠道数量。无恢复、无二次保存按钮，至少保留一条渠道。
- 保存期间阻止重复移除和同一页面其他模板写操作；失败保留列表和错误信息，可刷新模板后核对重试。
- 当前已经应用的报价清单保持不变，也不推进其编辑基准版本。版本冲突会阻止旧清单覆盖新模板；重新“一键应用”后才使用新模板继续编辑。
- 添加新渠道沿用“一键应用 → 添加渠道 → 更新模板”的既有流程和差异确认。
- 历史报价、客户报价、运费、审核状态、处理及成交状态均无修改路径。

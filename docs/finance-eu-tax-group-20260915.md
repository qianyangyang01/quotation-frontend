# 欧盟统一关税设置

## 功能与优先级

财务税率设置支持一条“欧盟（27国）”。添加后设置固定 USD/单金额，并统一维护物流商免税/不免税。报价目的地仍是实际国家，不会被改写成“欧盟”，也不自动增加常用国家或授权渠道。

匹配顺序：

1. 欧盟目的地使用指定三条云途 CHC 渠道，继续使用既有含包材整单计费重量的欧元公式。
2. 已选择的单独国家关税设置（包括零金额）优先。
3. 没有单独设置的欧盟成员国使用“欧盟”配置。
4. 其余情况沿用既有规则；同一报价不会叠加国家与欧盟两笔固定关税。

金额为 0 时不加固定关税；正金额但物流商未配置时保持“待设置”阻断。欧盟物流商列表取27国当前可用渠道的并集，按渠道标识去重。编辑可见物流商时保留暂时不可见物流商的原税务设置。

## 影响范围

- 前端关税计算和后端正式保存校验采用同一成员国资源 `backend/src/main/resources/eu-member-states.json`，覆盖中文、英文、国家代码。
- 三种报价模式和单品/组合 SKU 复用原关税调用路径，整单只加一次固定费。
- 附加费保持独立、按原单独国家规则匹配；不引入欧盟附加费分组。
- 原关税 JSON 保存结构和版本冲突保护保持不变，无新增 API 或数据库迁移。
- 历史报价保持已保存快照；不批量重算、改写历史记录、物流授权或正式价格。
- 前端 Docker 构建仅增加共享成员国 JSON 的包含规则，不包含其余后端源码。实际 Docker 上下文复制验证通过。

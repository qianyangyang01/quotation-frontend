## 防漏更新代码（本地完成，尚未部署）

此前从新版原表只提取新增渠道，旧渠道没有进入批次；成功发布新增渠道不能表示同物流商全部价格已更新。

- 读取批次时，服务端将涉及物流商的已启用、未归档、已有正式版本的渠道与批次渠道 ID 对照。
- 批次页面显示纳入数量和未纳入渠道清单，包括当前版本与来源文件。对无变化渠道仅表示已纳入核对，不声称重新发布。
- 局部导入必须明确确认其余渠道保留原价；一键发布接口在任何价格写入前重新计算清单，缺少确认则拒绝。
- 确认绑定未纳入清单及其现行版本，清单或来源变化使旧确认失效。页面支持重新核对并清除原确认。
- 发布结果及审计记录保留覆盖清单和局部确认；发布成功提示继续说明未纳入数量。单渠道发布按钮明确标为“仅发布此渠道价格”。
- 导入仍在 queued/processing 状态时禁止一键发布。继续使用既有价格基线、计费验收和幂等机制。

这是对导入覆盖范围的校验，不能自动知道用户尚未提供的更新原表，也不自动发布其他渠道。单渠道明确发布仍然仅修改该渠道。

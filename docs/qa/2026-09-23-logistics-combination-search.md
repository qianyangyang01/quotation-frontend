## 匹配规则

- 保留部分名称搜索，不区分英文大小写。
- 空格、全角空格和其他 Unicode 空白分隔多个关键词；所有关键词须同时匹配同一渠道。
- 完整物流商名称可以与渠道片段连写。例如“云途化妆品”“化妆品云途”“云途 化妆品”“化妆品 云途”均匹配上述渠道。
- 国家、物流属性、指定物流库继续独立筛选。名称匹配在渠道层完成，之后再计算价格行总数和分页。
- `%`、`_`、引号、正则符号按普通文字处理。没有引入通配符、逐字跳跃匹配或错别字纠正。
- 列表使用参数化 SQL，导出使用等价 Java 匹配；下载快照校验仍绑定原始筛选参数和价格版本。

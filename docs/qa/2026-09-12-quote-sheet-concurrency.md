## 真实浏览器

使用本地真实 Vue 和 Canvas 组件，虚构数据，无业务接口连接。

1. 手填 USD 88.88 → 新增重复数量 2，价格输入禁用 → 改为 8；真实 Ctrl+V 粘贴 TSV，原 88.88 保留。
2. 5 个数量列生成 PNG；实际 Ctrl+V 粘贴 PNG 与预览均为 1680 x 1014。
3. 第二标签页通过真实 Web Locks 占用客户报价复制锁（模拟尚未结束的系统复制）。第一标签页 PNG 和 TSV 均提示“其他报价单正在复制”；第二页释放后第一页面立即复制成功。未排队写入过时报价。
4. 浏览器未观察到控制台错误。原本地预览地址可继续使用。

## 边界

本轮并发针对客户端事件、异步编码及共享剪贴板；未在生产进行破坏性压力测试或创建测试业务记录。不同浏览器/不同用户不共享客户端编辑状态；Web Locks 仅覆盖同浏览器同源标签页，不支持 Web Locks 时仍保护同页组件。已提交给系统剪贴板的写入无法强制撤销，源报价发生变化时仍明确提示重新复制。未将本地 Ctrl+V 验证描述为 Excel/微信客户端验收。

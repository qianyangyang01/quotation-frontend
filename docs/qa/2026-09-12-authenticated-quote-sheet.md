# 已登录报价单异常与并发验收

## 范围

在用户已登录的 Codex 浏览器测试生产版本 quotation-2026.09.12-02。三个标签页共用同一个现有账号会话，分别是当前 13 渠道报价、个人记录 7 渠道报价、公司记录 1 渠道报价。未创建额外账号或会话，未做保存、成交回填、模板更新等业务写操作。这是界面并发验收，不是多用户服务器容量测试。

## 真实 UI 结果

| 场景 | 结果 |
| --- | --- |
| 空署名 | 图片被拦截并显示明确错误；表格仍可复制 |
| 空日期 | 图片被拦截并显示有效日期提示 |
| 超长署名 | 提示缩短姓名；图片复制按钮禁用 |
| 非英文时效 | 图片和表格复制都被拦截，明确指出行号 |
| 空时效 | 显示破折号，没有生成运输承诺 |
| 修改后再复制 | 旧图片立即移除，复制图片按钮禁用；重新预览后使用修改值，金额不变 |
| 双击预览 | 只出现一份预览，无未捕获错误 |
| 三标签页同时生成 | 13/7/1 条渠道及对应金额各自独立 |
| 五轮并发编辑与重建 | 15 次重建全部完成；每轮旧图均清除且禁用复制，重建后渠道数保持 13/7/1 |
| 并发图片复制 | 三页均显示复制成功，各自预览仍保留；未把提示成功等同于外部聊天粘贴验收 |
| 并发双击表格复制 | 三页分别报告 13/7/1 条，未出现错误 |
| 同记录关闭、重开图片弹窗 | 当前页面临时姓名和时效保留，其他标签页不变 |
| 切换记录 | 临时姓名及 99–100 days 未带入另一记录 |
| 离开记录后重开原记录 | 原时效恢复，临时修改未写入记录 |
| 触发生成后立即关闭 | 弹窗与图片消失，无迟到预览重新出现 |
| 控制台 | 三个验收页面未记录 error 日志 |

五轮编辑、重建、等待图片可见并核对表格的端到端耗时为 970、908、936、893、905 毫秒。这包含浏览器自动化开销，只能说明本次 3 标签页操作表现，不代表后端接口时延、吞吐上限或大量用户容量。

表格实际键盘粘贴在报价单临时署名输入框中完成，随后立即恢复署名。粘贴结果含所有 13 条渠道及美元数值，没有内部渠道编码或人民币。单行输入框会去除换行，因此不能作为 Excel/WPS 单元格分列验收。浏览器剪贴板读取接口返回空，与真实粘贴成功不同，未依据该接口判断复制失败。

浏览器工具 fill('') 未清空输入，改用全选及 Backspace 后观察输入确实为空，才执行并记录空值用例。未生效的初次填值不计入通过。

## 发现并修复的实际遗漏

历史记录 QT20260911094203BD99E4 的两个 JITO 澳大利亚分区渠道保存了 `该物流暂无时效说明`。旧展示模型将其当作待翻译的中文时效，导致整张图片及表格被拦截。

该文字正是 `formatLogisticsEta` 对 missing/conflict 数据输出的缺失占位值，应在客户报价单显示 `—`。本次仅在前端展示层兼容该精确占位值；其他中文异常时效仍需补填。增加真实物流格式化函数与客户报价单的集成回归，以及历史占位值预览、复制、手动补充、恢复的组件回归。原物流及历史记录没有修改。

## 数据安全比对

UI 测试前后只读聚合校验一致：

- 正式报价 93 条，全行排序摘要相同。
- 当前登录账号草稿 1 条，全行摘要相同。
- 模板 11 条、财务配置 6 条、物流商资料 27 条，全行摘要分别相同。
- 素材表记录数保持 200。

摘要包含行内容和版本/更新时间，比较并非仅计数。没有为验收创建正式报价或改写财务、物流资料。

## 限制

只有一个超级管理员会话，不代表销售员权限矩阵或独立多用户会话已验收。三个标签页共用系统剪贴板，最后一次成功复制覆盖前一次属于剪贴板正常行为。

独立 data: 内存粘贴页被浏览器 URL 安全策略拦截，未绕过。真实 Excel/WPS 分列和聊天软件图片粘贴仍未验收；页面 PNG 已实际生成，外部粘贴结果不由按钮提示推断。

发现缺失时效问题后的修复版本、CI 及发布后真实记录复验结果，记录在对应发布包的 RELEASE.md。

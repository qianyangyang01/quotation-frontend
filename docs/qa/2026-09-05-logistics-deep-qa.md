# 物流与跨角色深度测试（2026-09-05）

基线：quotation-2026.09.05-07，26af93381b81e2b040a8ab2f47f9277f7098aebe。本文记录修复候选的本地验收；生产发布及两条报价的实际编号另见最终交付记录，不将本地通过等同于线上验收。

## 测试边界与结论

使用独立 quotation-deep-qa PostgreSQL/Redis/MinIO 容器、独立卷与账号。故障注入、并发及异常数据均在隔离库执行；生产仅创建明确标记的 QA 验收账号和报价，不改真实物流价格或培训系统。测试期间用户自行发布了原批次 99 个渠道，页面显示成功 99、失败 0；本次未自动发布该真实批次。

确认并修复以下问题：既有会话撤权不及时、报价重复并发保存、空选择误发布全部渠道、批量发布并发返回不一致、负数金额和畸形采购请求缺少校验、大工作簿内存耗尽，以及账号操作和报价条件提示不清楚。修复维持公斤价 × 计费重量 + 每票费；首重续重过滤，缺时效允许报价，真实价格重叠仍阻止发布。

## 发现与修复

| 问题 | 修复 | 证据 |
|---|---|---|
| P1 停用/降权后旧会话仍有权限 | 请求时重新核对账号、密码版本及权限，失效会话立即退出 | 实际账号登录：降权 403、停用 401 |
| P1 同键并发保存 8 次生成 8 条报价 | 数据库事务锁串行处理相同账号/操作/幂等键 | 8 次实际并发均成功但仅 1 个记录 ID |
| P1 selections=[] 发布全部 88 条 | 空选择、重复/错误 UUID、非本批次与渠道不匹配在写入前拒绝 | 空选择及错误批次 422，数据库未误发布 |
| P1 批量发布并发重试出现成功 2 条与成功 0 条的不同结果 | 短事务持久化处理占位，保留逐渠道独立事务，完成后重放同一结果 | 三并发仅一次执行；其余 409 明确正在处理；完成重试结果相同 |
| P1 财务/报价接受负数金额 | 汇率正数、金额非负、成交数量正整数；保持可选空值兼容 | 非法金额 422；旧财务版本 409 |
| P1 采购畸形对象/负数字段缺少明确校验 | 对象结构与价格/重量/数量校验 | 单元复现及真实 HTTP 422；不把此前未完成的 HTTP 请求当成失败证据 |
| P1 格式膨胀 Excel 导入在 1 GB 后端耗尽堆内存 | 流式剔除纯格式空行中的单元格，保留行列位置、合并、公式/值；串行 POI 解析；OOM 退出后允许容器重启 | 原 15 份文件回归；4 份实际上传 112 渠道在 42.7 秒内完成，无 OOM |
| P2 账号加载失败显示空列表，创建无反馈 | 加载/错误/重试、请求超时、提交中防重复 | 前端回归与构建；管理员线上实际创建 QA 账号 |
| P2 默认国家需要分区时显示无渠道，但其他国家可用 | 默认试算寻找实际可用国家；未选分区明确提示选择报价区域 | 业务员页面复现后修复；分区选择恢复渠道价格 |

发布占位的异常恢复窗口为 15 分钟；进程在途中退出可于窗口后重试，已发布渠道仍独立保留。此轮未模拟超过 15 分钟的单批发布，不能宣称无限时长的互斥保证。

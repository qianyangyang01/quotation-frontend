# 客户报价单异常修复与回归验收

## 原因与处理

生产只读物流商清单有 14 个名称，原显示映射缺少 8 个。花海、闪电猴等名称变成破折号，并使整个图片及 TSV 导出被统一校验阻止；长表格底部的提示又使失败原因不可见。

- 补齐现有 14 个物流商显示名；Hua Hai、Rongding、Baizhou 为可读拼音显示名，不修改物流商主数据。保留 SFYD Express 与 YunExpress 的区别。
- 未识别名称在编辑区上方补填英文，同一物流商共用一次补填；切换报价上下文清空，离开页面不保留。
- 错误提示移到按钮旁边；记录弹窗外复制失败时可直接打开报价单检查。
- 表格复制独立校验导出的表格字段，不受不参与 TSV 导出的署名、日期影响。图片仍严格校验署名和日期。
- 异常测试发现同步监听在 reverse/sort/splice 中间状态误删时效编辑。现同步废弃旧图片，Vue 完成本次数据更新后再清理移除渠道的编辑。
- 异步复制完成时检查记录上下文，避免旧记录状态显示到新记录。素材加载增加 15 秒超时，失败可重新加载。

## 边界与其他模块

运行时代码只涉及展示模型、客户报价单组件、记录复制组件及图片渲染器。报价计算、保存接口、后端、数据库迁移、采购、物流导入和培训系统代码未修改。原报价矩阵 Excel 复制逻辑保持原样。

生产调查只读取物流商名称；浏览器异常测试使用独立本地上下文和合成数据，不调用业务 API。监测 Storage.setItem、IndexedDB.open、所有网络请求：没有业务 API、写请求或存储写入。图片仅为内存 Blob，关闭释放 Object URL，没有生成图片文件、上传或下载。

## 验证

- 全量前端回归覆盖金额精度、三种报价矩阵、采购、物流、记录等现有测试。类型检查、Lint、生产构建通过。
- 专项单元/组件回归：14 个物流商、未知名补填/去重/清空、国家简称、同物流商不同渠道及区域、空时效、零/空价格、自定义数量和套数、日期非法、公式注入防护、重排、重算、切换上下文、旧渲染完成、旧复制完成、未就绪源、权限拒绝、不支持剪贴板、图片释放、记录关闭/切换、素材超时及重试。
- 独立 Edge 实测真实文本剪贴板并粘贴到浏览器编辑区：14 条记录、9 列，内部渠道信息未泄露。实际 PNG 剪贴板解码后逐像素哈希与页面预览相同。
- 图片实际渲染 6/24/25/49 行分别为 1/1/2/3 张；6 行为 1536×1024；49 行覆盖 1–24、25–48、49，未遗漏渠道。Logo、表头和四条说明素材未改变。
- 三种已保存报价模式分别验证记录底部数据复制、打开图片预览、关闭释放，使用记录保存的美元值和套数；原记录对象未变更。
- 注入素材请求失败，按钮附近显示原因；恢复请求后可以成功预览。无未捕获浏览器异常。

自动化测试文件：`CustomerQuoteSheet.test.ts`、`QuotationRecordCopyActions.test.ts`、`customerQuoteSheetAssets.test.ts` 及已有模型、剪贴板、记录适配测试。

浏览器脚本：`scripts/qa/customer-quote-sheet.mjs`。启动该工作树 Vite 5181 端口后，设置 `QUOTE_QA_MODULE_ROOT` 为包含 Playwright 的外部 Node 模块根路径（绝对路径且以 `/` 结束），`QUOTE_QA_BROWSER` 为 Edge/Chromium 可执行文件，再用 Node 执行脚本。脚本只允许 loopback 地址、创建独立 headless 浏览器，不接管任何登录会话。输出 JSON 验证结果，图片不落盘。

## 未完成的验收边界

Codex 右侧浏览器控制工具初始化报 `failed to write kernel assets: 系统找不到指定的路径`。因此没有完成用户已登录生产页面的实际点击、真实 Excel/WPS 或聊天软件粘贴验收。独立浏览器结果不能替代这些验收，不能据此声称线上已登录操作全部通过。

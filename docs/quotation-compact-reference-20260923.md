# 报价页面紧凑排版

基线：线上 quotation-2026.09.23-19 / bd93c4f64a8c2e4d704ac3080b970e60ff90c38f。
按本任务用户确认的浅橙／浅蓝／浅绿／浅紫参考图实现，在独立工作区开发；没有重新合入已撤销的旧布局提交。

## 改动范围

- 报价条件：桌面宽度大于1250px时，客户、模式、SKU、物流属性、客户等级、采购阶梯、佣金阈值及查询按钮横向排列。组合模式保留查询全部SKU；较窄屏幕自动分为4列、2列、1列。
- 成本与重量：商品信息移入标题栏的插槽，保留商品图片／分类、SKU、采购、库存、数据源及加载状态。采购价、重量来源、国内运费、特殊包装、总成本及重量摘要横向排列，手动重量和计抛信息按原条件出现。
- 页首去掉重复的流程条和大标题说明，保留报价模式、币种、状态、汇率、报价人、计算规则及草稿错误／冲突操作。
- 三种渠道模式保留原组件和事件，统一浅绿色主区，压缩国家与渠道卡片间距。
- 预览区使用浅紫色标题，压缩统计卡、基本信息和编辑器间距。所有报价单编辑、列排序、图片、复制、保存和错误提示保留。
- 新增 quotationCompact.css，所有规则限制在 .jerry-app .quotation-page 内。共享的客户报价单组件源码和导出／计算服务没有改动。

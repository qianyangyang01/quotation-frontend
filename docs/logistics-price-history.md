# 渠道价格变动

本次基于线上版本5d34e772，保留已有物流日期、导入和计费规则。V64仅新增展示派生表，不更新历史报价或正式物流价格。

发布事务成功提交后，由独立单线程计算缺失的展示结果。计算/写入失败不回滚业务发布；后台任务合并、SQL限时及展示并发限制，不自动循环重试。完成事件或手动按钮刷新一次，超时保留上次数据并提示；展示组件报错仍可返回运费规则。

十个重点国家、原表重点属性和渠道优先。未唯一匹配项以普通说明及明确候选ID展示，系统渠道和分区各自保留真实价格历史，不把候选认定为同一渠道。默认1kg，支持三版比较、年内已记录最低及日期、2025-01-01至2026-10-01加权均价；历史不足不补算。

通知覆盖同一浏览器同源标签，不是跨设备推送。前后端与V64一起部署。首次历史补算可能较久，读取复用已有结果；回滚使用上一版镜像并保留向后兼容的派生表，不回退业务数据。

验证覆盖计算/写入失败、锁超时、重复刷新、坏数据、组件异常、完整导入审核发布与保存报价整行不变。生产验收仅只读，不导入测试价格或创建业务报价。

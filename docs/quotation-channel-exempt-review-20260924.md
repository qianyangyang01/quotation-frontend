# 手动同渠道免审状态

用户确认：只增加“同渠道免审”供审核人员手动选择，不自动通过其他报价，不建立渠道白名单或商品匹配规则。

## 行为与联动

- 审核结果弹窗增加蓝色“同渠道免审 / 可报价 · 不再审核”，内部值为 `channel-exempt`。保留既有管理员、财务审核权限，以及先领取、当前审核人、报价版本和审核版本校验。
- 完成后结束当前占用，记录审核人、审核时间和审核历史。它是独立结论，不属于待审核、审核中、审核通过或价格异常。
- 记录分组筛选、后端列表/统计/分页/导出共用该状态；员工与管理员读取同一状态。对账数据和审核历史通过统一标签函数显示“同渠道免审”。
- 审核状态与处理状态、成交状态独立。选择状态不修改报价金额、物流快照、客户报价、成交数据、记录版本或业务修改时间。
- 新报价、再次发起的报价仍从待审核开始；同渠道其他记录不变。主动修改客户价格或撤回编辑按既有规则令原结论失效，保留原审核历史；仅保存相同价格不重置状态。
- 原有“重新审核”保留供有权限人员主动纠正结论；系统不会主动再次领取审核。已完成结论仍受既有归档/回收站保护。
- 物流导入、发布、回滚和计费规则更新不触发本功能，也不回写历史报价。

## 数据库和发布

新增 V53 仅扩展 `quotation_review_status_check`，不修改已有记录；保持审核人占用约束。没有改写既有迁移。

本次在独立工作区基于 `2f016165c734c354ca9879193e21f968dcf69291` 实现，未发布生产。前后端和迁移必须配套上线。合并其他并行工作时须复核迁移编号是否冲突。已有新状态数据后，回退旧前后端可能将其误显示为待审核，回滚应保留新状态读写兼容性，不能将业务数据强行改写为审核通过。

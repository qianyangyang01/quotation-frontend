# 采购报价日期筛选与 SKU 下载

在“采购资料维护”主列表上方，现有搜索框和“重置筛选”所在工具栏中增加“报价日期”起止日期及“下载筛选 SKU”。普通采购和 FOB 列表行同时显示报价日期。

日期与关键词搜索共同作用，包含起止当天，允许只填一端。修改条件自动回到第一页；重置清空关键词及日期。开始日期晚于结束日期时显示提示并禁用下载。无结果或列表读取中禁用下载。保存编辑后在有筛选条件时重新查询，避免将范围外记录插入当前结果。

下载为 Excel，包含 SKU、报价日期、报价人、类别、数据来源，覆盖全部匹配记录，不受分页影响。同 SKU 属于不同采购来源时保留各来源记录，便于核对。SKU 和其他单元格写为文本，不执行公式。列表与导出共用服务器筛选规则和权限判断，导出使用一次只读数据库快照，不读取图片。

按采购资料 `quotationDate` 筛选，不使用更新时间替代。支持明确的年月日（横线、斜杠、点分隔）；空白、无效或不可识别的日期在设置日期条件后排除，未设置日期条件时仍可正常查询。不改写原始日期或其他采购字段。

前后端需一起发布，无数据库迁移。日期安全解析使用现有 PostgreSQL 16 的 `pg_input_is_valid`。没有修改历史报价、价格、审核状态或成交状态。

本地分支 `codex/purchase-date-export-20261109`，基于 `73a1222c`，未包含其他尚未发布的本地功能；正式发布前应重新核对当前生产基线。

本次完成本地开发，尚未部署生产。前端采购工作台及目录服务 50 项测试通过，类型检查和生产构建通过。PostgreSQL 集成验证覆盖日期边界、单日/单边范围、无效日期、跨页导出、原数据不变、普通采购与 FOB 权限和空结果下载；原有私有源工作簿用例因文件不在 Git 中按原规则跳过。

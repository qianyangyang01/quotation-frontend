## 解析及计费

- 按标题、产品代码、表头读取，价格、日期、行号及最低重量不写死。固定公司渠道 ID 保证后续改价对应原渠道。
- 燕文读取“产品号”及每条价格的“最小计费重量(KG)”列。缺失起重依据或重量范围、产品代码不符时阻断，防止部分价格替换。
- 燕文“价格使用说明”之后的国家要求表不再沿用价格列；国家级时效仍由既有时效提取器读取。
- 万邦使用“重量段”，而不是“重量限制”；按原表公斤价乘计费重量，加一次操作费。退件、重派和偏远附加费表不作为主运价。
- 先按各国家起重补重，再匹配重量段。保留原表0.1至0.101kg、10至10.001kg等间隙，间隙内不猜档报价。没有明确进位规则的渠道不套用云途1g进位或巧捷500g进位。
- 不把无关文字说明变为额外基础运费；不额外实现偏远、税费、尺寸或体积重功能。
